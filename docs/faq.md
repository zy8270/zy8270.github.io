# 常见问题

## 安装

### 装不上 / 提示"未知来源应用"

APK 从 GitHub Releases 下载，属侧载安装，系统必然提示。在系统设置里为本文件管理器或浏览器允许安装未知应用即可。

### 覆盖安装会丢数据吗？

不会。工程组、模板、字段值、设置都保存在 DataStore，覆盖升级全部保留。

### 需要什么系统版本？

Android 7.0（API 24）及以上。液态玻璃实时折射需 Android 13 及以上。

### 启动闪退？

- Android 9 及以下：v0.6.12 及之前存在无存储权限查询媒体崩溃的问题，v0.6.13 已修复，请升级
- 其他：到 [Issues](https://github.com/zy8270/engCamera/issues) 反馈机型、系统版本、复现步骤

## 拍照与录像

### 快门按了没反应？

- 相机未就绪（刚启动或刚从编辑器返回）→ 等 1~2 秒
- 录像模式下快门是开始录像，不是拍照
- 检查相机权限

### 拍出来水印位置和预览不一样？

不应该。预览与烧录共用同一套排版代码。若发现差异请反馈机型、模板、持机方向。

### 连拍会中断？

开启「拍照后确认」时每张都要走确认页。想连拍请关闭该设置。

### 照片很糊？

- 画质档位选了低分辨率
- 变焦倍数过高（电子变焦是裁切）
- 暗光下对焦失准 → 点一下主体再拍

### 音量键没反应？

设置 → 音量键拍照 → 确认开启。

### 录像没有水印？

看合成提示：
- "已保留原片" / "已保存无水印视频" → 合成失败降级
- 尝试降低录像画质档位

### 录像时间不动？

网页模板时间定格在开录时刻。换原生模板即可走秒。

## 水印与模板

### 换了模板，我填的内容没了？

字段值按类型对位保留。如果新模板没有该类型字段位，切回原模板即可看到。

### 模板选择器闪退？

v0.6.13 修复了打卡系列模板的字段 id 冲突闪退。升级到最新版。

### 液态玻璃不折射？

- 需 Android 13+
- 编辑器点眼睛开实时预览确认
- 低版本自动退化为半透明玻璃底

### 圆角拉满变形？

50% 是正半圆封顶，超过会导致 SDF 退化。建议 15%~50%。

### 水印太宽/太窄？

编辑器 → 模板选项 → 水印宽度滑杆。

### 能自己做模板吗？

网页模板可以：导出 HTML → 改样式 → 导入。原生模板需改源码。

## 定位与天气

### 位置一直"未获取定位"

编辑器里位置字段对话框给出三态提示：去授权 / 去开启 / 刷新定位。

### 地址只有"中国"

系统 Geocoder 太粗（常见于无 GMS 机型）。应用会降级在线反查；无网时显示裸坐标。连网点"刷新定位"。

### 地址里带着"邮政编码: xxx"？

那是系统地理编码返回的原文。进位置字段 →「地址选项」，把「邮编」层级关掉即可（默认就是关的）。

### 地址太长，只想留市和区？

位置字段 →「地址选项」→ 关掉不需要的层级，还能用 `↑` `↓` 调顺序。

### 天气不更新

有缓存。点"刷新天气"强制更新。

### 相机页老是有定位提示条？

只对曾授权过定位的用户显示。右侧 X 可关闭，系统打开定位后自动恢复。

## 标注与批量

### 确认页相机黑屏？

正常设计——确认页期间相机关闭。返回后自动重绑。

### 标注画不出来？

确认工具已选中，且手指落在照片区域内（白框外不响应）。

### 文字白框会烧录吗？

不会。白框只是 UI 提示。

### 双指放大后笔画太细？

设计如此——笔画粗细定格在落笔时的倍率，与成片一致。

### 批量加水印最多几张？

30 张，更多请分多次。

### 批量处理完原图会变吗？

不会，新文件另存。

## 连拍拼图

### 连拍的照片在哪？

在应用缓存里，不进相册。只有「保存拼图」合成的那张整页才进相册。

### 拼图里的相册图片为什么没水印？

设计如此——相册图片按原样贴入，水印只烧相机拍的那些。预览里带「相册」小徽标的就是这类。

### 横图上下有大片留白？

3:4 等格模板（马克-工作 / 今日-客户 / 今日-工作）格子固定 3:4，横图按宽度内嵌自然上下留白。想填满就换公文风模板并选多列。

### 能拼几张？

受内存预算限制。实测 2 列 4 张（约 71MP）、1 列 4 张（约 56MP）都能保持原生分辨率；更多张时整体等比缩小并提示实际尺寸。

### 保存到一半取消了？

连拍缓存会保留，可以重来。但 JPEG 编码本身不可中断，在编码阶段取消可能留下不完整文件。

### 退出拼图会丢照片吗？

会，所以有二次确认。确认退出后缓存清空。

## 防伪码与品牌角标

### 右下角多了一块东西？

品牌角标，默认开。不想要就去编辑器 →「防伪码&品牌」关掉。

### 防伪码能证明照片是我拍的吗？

不能。它是**内容指纹**（发现照片被改过），不是密码学签名。盐只起混淆作用，知道算法的人可以重算伪造。

### 带批注的照片为什么校验不了？

指纹算在未加水印、未批注的原始画面上，批注改变了画面内容。水印版本身可校验（先算码再烧水印）。

### 防伪码预览里的那串字是真的吗？

不是，预览显示的是占位符。真实码要等成片才算得出（要基于画面内容）。

### 能换成我自己的品牌图吗？

能。「防伪码&品牌」→「选择图片」从相册导入，整块替换（按画面宽 16% 等比缩放）。导入图片后文字输入不生效，这是设计如此。

### 视频里有角标吗？

没有。角标与防伪码只出现在照片与拼图里。

## 保存与文件

### 照片存哪了？

默认 `DCIM/Camera/`，文件名 `engCamera_<工程名>_<时间>.jpg`。

### 系统相册看不到？

MediaStore 缓存延迟，下拉刷新相册应用。

### 提示"无法写入所选目录"？

SAF 授权失效。设置里重新选择保存文件夹或恢复默认。

### 文件名中文乱码？

传输工具的问题，文件本身没问题。

## 语言与主题

### 切换语言后部分文字还是中文？

未翻译的新文案（持续补齐）。你自己填的标签不翻译。

### 夜间模式看不清水印？

水印颜色是模板设置，不跟随主题。到编辑器调文字颜色。

### 水印为什么不跟随明暗主题？

水印画进照片，必须与界面主题无关。

## 其他

目前无开关。检查静默，失败不打扰。
