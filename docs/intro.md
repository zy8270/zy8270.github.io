# 介绍

**工程水印相机（engCamera）** 是一款 Android 端的工程水印相机：拍照 / 录像前在取景器里实时预览水印，按下快门就把水印**烧录**进成片文件——不需要后期，不依赖元数据，发给谁都看得见。

它没有账号、没有广告、没有云同步，所有水印配置和照片都留在你自己的手机上。源码以 MIT 协议开源。

## 什么是 engCamera

市面上的水印相机大致分两类：一类把水印当作**叠加层**记录在图片元数据或私有格式里，换台设备或换个看图软件就消失；另一类必须联网、登录、付费，把照片传到服务端再合成。

engCamera 选择第三条路：**水印在本地直接画进像素**。

- 拍照时，水印渲染器按取景器的最终尺寸排版，把水印画到 JPEG 位图上
- 录像时，Media3 Transformer 逐帧回调，把水印画到每一帧上
- 给相册已有图片加水印时，同一套渲染器按图片自身分辨率重绘

于是「预览看到什么样，成片就是什么样」成为一条硬约束，而不是一句宣传语。

## 为什么做这个应用

因为被广告恶心到了，且 AI 正好赋予了我掀桌子的效率与技术实力。

市面上很多水印相机把水印当"贴纸"叠在图上，换个看图软件就没了；也有不少要登录、要会员、要上传。既然这些事一台手机就能自己做完，那就自己做。

## 主要特点

### 1. 所见即所得的水印

预览浮层与烧录渲染共用同一套排版代码（字号、行高、间距、内边距全部按画面宽度比例计算），因此不同分辨率下比例一致，不会出现"预览一行、成片两行"的错位。

液态玻璃模板更进一步：预览用 AGSL 实时着色器折射相机画面，成片用同款着色器的 CPU 移植，肉眼几乎无法分辨差异。

### 2. 15 款模板，各有脾气

- **原生 13 款**（Canvas 直绘，零额外开销）：经典工程蓝、液态玻璃、今日·工程、今日·打卡、今日·打卡1、马克·工程、马克·工程白、马克·打卡、极简白影、边框卡片、单行横排、渐变底栏、便签卡
- **网页 2 款**（HTML/CSS 离屏渲染）：胶片场记、杂志卡片

每款模板暴露自己的可调项（标题 / 正文颜色、水印宽度、圆角、渐变基色、阴影、记录点……），随工程一起保存。网页模板还能整份导出成 HTML，改完再导入。

### 3. 字段系统

水印内容由「字段」组成：工程名称（标题）、时间、位置、天气、备注、计数，以及任意自定义字段。

- 可**增删、拖动排序、启用隐藏**
- 时间 / 位置 / 天气支持**手动定格**（会打上"自定义"标记），也可一键重置回自动
- 计数在每次保存后自动 +1
- 位置文本可选择是否在尾部附加经纬度

### 4. 工程组

多工地作业时，每个工地一套水印。工程组就是"整套水印配置"的快照：

- 新建工程 = 复制当前工程的水印内容，切换后各自独立修改
- 相机底栏左侧常驻工程组入口，不用进编辑器就能换
- 保存的文件名自动带工程名，如 `engCamera_一号工地_20261021_102019.jpg`

### 5. 拍照确认与标注

开启「拍照后确认」后，快门不会直接落盘，而是先进确认页：

- 箭头 / 矩形 / 笔刷标注，六色 + 自由选色，逐笔撤销
- 点按加文字，拖动移动、拉杆旋转缩放、即时改色
- **长按水印块可拖动改位**，只影响本次保存，不动全局设置
- 双指缩放：放大后松手保持缩放，单指继续落笔，笔画粗细定格在落笔时的倍率

### 6. 重力方向跟随

水印位置九宫格与拖动都按**物理重力方向**解释：横拍时选「下方」，水印就出现在桌面所在那一侧；倒置拍照也不会跑到头顶。文字恒正立。

### 7. 中英双语与明暗主题

界面文案、模板名、字段标签全量支持中英切换（跟随系统 / 中文 / English），主题支持跟随系统 / 日间 / 夜间。

## 技术栈

| 项 | 选型 |
| --- | --- |
| 语言 / UI | Kotlin + Jetpack Compose（Material3） |
| 相机 | CameraX 1.6.2（多用例常绑 + ViewPort 统一比例 + TextureView 预览） |
| 视频水印 | Media3 Transformer 1.11.1（录后转码烧入） |
| 网页模板 | WebView 离屏渲染（WebView 池并行 + LRU 缓存 + 磁盘缩略图） |
| 液态玻璃 | [AndroidLiquidGlassView](https://github.com/QmDeve/AndroidLiquidGlassView)（AGSL 实时折射，MIT）+ 同款着色器 CPU 烧录移植 |
| 定位 / 天气 | FusedLocationProvider + Geocoder + 在线反查 + Open-Meteo |
| 持久化 | DataStore Preferences + kotlinx.serialization |
| 相册 | MediaStore + Coil |

## 兼容性

- **minSdk 24**：Android 7.0 及以上
- **targetSdk 36**
- 液态玻璃实时折射需 **Android 13+**，低版本自动退化为半透明玻璃底（内容与排版不变）
- 多镜头 / 电子变焦 / 4K 等能力取决于设备，应用内只显示设备真实支持的档位

## 已验证设备

- Redmi Note 12 Turbo（Android 15 / HyperOS）：四方向拍照、录像比例与水印、点击对焦、批量加水印、工程组、天气
- iQOO Neo 10 Pro（无完整 GMS）：中文地址多级兜底拼接
- Android 模拟器（带 GMS）：定位 / 天气 / 网页水印模板全链路
- 本页截图即取自 Android 模拟器（Pixel 10 Pro / Android 16）
