# 多工地：工程组切换

一个工程组 = 一整套水印配置。管多个工地时，这是最省事的设计。

## 为什么要用工程组

假设你同时管三个工地：

| 不用工程组 | 用工程组 |
| --- | --- |
| 每次换工地都要进编辑器改工程名 | 底栏一点切换 |
| 容易忘记改，拍出张冠李戴的照片 | 文件名自带工程名，错不了 |
| 各工地的水印样式混在一起 | 各自独立，互不影响 |

## 建组的三步

### 1. 先把"母版"调好

在默认工程里把水印调到满意：模板、颜色、字段、位置全部定好。

### 2. 逐个新建

点工程组 → `+ 新建` → 输入工程名 → 创建。

新工程会**复制**当前工程的全部水印配置，所以创建出来的工程和母版一模一样，只是名字不同。

::: tip 工程名自动作标题
设置项「工程名作水印标题」默认开——新建工程时，工程名自动填入水印标题。所以你起的名字直接就是水印上的标题。
:::

### 3. 按需微调

每个工程可以独立改：

- 水印标题（通常已经自动填好）
- 备注的默认内容（比如固定写"日常巡检"）
- 位置（不同工地地址不同，但一般让定位自动填）
- 模板样式（不同项目甲方要求不同配色）

## 现场切换

**相机页底栏左侧**的三横线按钮 → 点工程名 → 切完继续拍。

切换后立即生效：

- 相机页水印变了
- 文件名前缀变了
- 编辑器标题显示新工程名

::: tip 快捷切换
不用进编辑器。工地上来回跑时，这个入口就在快门左边一格。
:::

## 文件名的作用

```
engCamera_一号工地_20261104_093012.jpg
engCamera_二号工地_20261104_104533.jpg
engCamera_三号工地_20261104_140012.jpg
```

一天跑三个工地，照片全在一个相册里，但按文件名一眼能分开。

## 重命名

点工程行右侧的铅笔图标。

::: warning 重命名只改工程名
它影响文件名与列表显示，**不改水印标题**。水印标题是字段数据，要单独在编辑器里改。
:::

## 批量操作

勾选多个工程：

| 操作 | 说明 |
| --- | --- |
| 删除 | 批量删除（至少保留一个） |
| 重置勾选的工程 | 恢复为初始水印状态 |

## 迁移到新手机

工程组不能一次性全部导出，需要逐个：

1. 切到工程 A → 编辑器 → 水印模板 → 导出 → 全量导出到剪贴板
2. 存起来
3. 新手机上建同名工程 → 导入 → 粘贴

::: tip 更省事的办法
如果各工地水印差异不大，只导出"母版"工程，新手机上导入后重建其他工程（新建时会复制母版）。
:::

## 实际配置示例

| 工程名 | 模板 | 备注默认值 | 特殊设置 |

## 常见问题

**切换工程后位置变了？**
位置是工程级数据。如果新工程没单独设过位置，用默认值。

**新建工程后水印没变？**
新建是"复制当前"，所以看起来一样。切换过去再改。

**能删掉当前工程吗？**
能，会自动切到剩下的第一个。最后一个不能删。
