# 补拍：给旧照片加水印

手机相册里那些"拍完就忘"的现场照片，现在可以补上水印。

## 什么时候需要

| 场景 | 说明 |
| --- | --- |
| 用系统相机拍的 | 后来才装上 engCamera |
| 同事发来的照片 | 需要用你的工程水印归档 |
| 旧手机迁移的照片 | 想把历史记录统一格式 |
| 截图/翻拍 | 需要标注说明 |

## 操作流程

### 1. 进入批量模式

相机页底栏中间偏左的**喷水图标**。

### 2. 选图

点中间的 `+` 或底栏蓝色下载键 → 系统图片选择器 → 多选（最多 30 张）→ 点"添加 (N)"。

### 3. 逐张标注

界面显示 `1/N`，当前是第几张。

| 想做的事 | 怎么做 |
| --- | --- |
| 画箭头/矩形/画笔 | 点工具条对应图标，在图上拖 |
| 加文字 | 选 `A`，点图上位置，输入文字 |
| 改颜色 | 点色点（标注会自动选中） |
| 改水印内容 | 点左下笔进编辑器 |
| 挪水印位置 | 长按水印块拖动 |
| 撤销 | 点右下撤销按钮 |

### 4. 保存并下一张

点中间蓝色按钮 → 当前张保存 → 自动进入下一张。

### 5. 完成

处理完全部张数后自动退出。

## 水印内容怎么定

批量模式的水印用的是**当前工程**的配置，时间/位置/天气取**当前时刻**（不是照片的原始拍摄时间）。

::: warning 时间不会自动回溯
批量加水印时，水印上的时间是"你处理这张照片的时刻"。如果需要照片原始时间，请在编辑器里手动填时间字段。
:::

::: tip 想统一改内容
点左下笔进编辑器改一次，之后所有张都用这个内容——这是批量处理的效率关键。
:::

## 水印方向

批量模式下水印**锁定与图片同向**，不跟随当前手机朝向。因为处理的是已拍好的照片，方向以照片为准。

## 液态玻璃的真实折射

选液态玻璃模板时，批量加水印也是**真实折射**：按图片全分辨率渲染，玻璃卡拖到哪里就扭到哪里。

## 原图安全

- 原图**不会被修改**
- 新文件另存为 `engCamera_<工程名>_<时间>.jpg`
- 处理完原图还在相册里

## 一次处理很多张

30 张上限是为了控制内存。更多张请分多次：

```
第 1 批：1~30
第 2 批：31~60
...
```

## 常见问题

**选图后加载很久？**
大图解码慢，等 1~2 秒。超大尺寸照片（如 108MP）会更久。

**水印位置和拍照时不一样？**
批量模式按图片尺寸重新排版，比例一致但绝对位置可能因宽高比不同略有差异。

**能只改某一张的水印吗？**
不能。批量模式的水印内容对整批统一（点左下笔改一次全部生效）。

**处理完的照片在哪？**
保存目录（默认 `DCIM/Camera`），和拍照的成片混在一起，文件名规则相同。
