# 工地说实话：从开工到竣工留痕

这篇讲的不是功能，而是**怎么把它用出价值**。

## 场景：一个普通的结构施工项目

假设你在管一栋楼的结构施工，需要每天留痕。传统做法是：手机拍照 → 事后手动记在 Excel → 照片靠文件名和记忆对应。三周后翻旧照片，你已经记不清"三层梁板"是哪张了。

用 engCamera 之后，流程变成：

```
到现场 → 打开应用 → 拍 → 完事
```

照片本身就带时间、地址、天气、施工部位。不需要事后补记。

## 第一步：把工程建好

**为每个项目建一个工程组。**

点底栏左侧的三横线按钮 → `+ 新建` → 输入工程名（如"XX 项目主体结构"）。

新建的工程会复制当前水印，所以第一步应该先把"默认工程"的水印调好：

1. 进编辑器，模板选「今日·工程」或「经典工程蓝」（信息密度高、正式）
2. 工程名称改成项目名
3. 备注先留空（现场填）
4. 保存

然后再新建工程，就自动带上这套配置。

## 第二步：现场怎么拍

### 每个工序拍三张

| 张数 | 拍什么 |
| --- | --- |
| 第 1 张 | **全景**：能看出在哪里、周围环境 |
| 第 2 张 | **细节**：关键节点、钢筋绑扎、预埋件 |
| 第 3 张 | **标识**：图纸、标牌、材料铭牌（证明"这是这个部位"） |

三张都在同一个水印配置下拍，时间连续，可信度最高。

### 备注怎么填

现场最省事的做法：进编辑器 → 点「备注」→ 写部位 → 点「确定并保存」→ 直接回相机继续拍。

备注写法建议：

```
三层梁板钢筋绑扎完成
四层柱钢筋隐蔽验收
东侧外墙防水施工
```

::: tip 短句优于长句
备注会显示在水印里，太长会挤占画面。**部位 + 工序 + 状态**，10~15 个字足够。
:::

### 收工前补一张

如果当天忘了拍，第二天补拍时：

1. 进编辑器，把**时间**手动改成昨天（定格）
2. 拍完再点「重置」恢复自动

::: warning 别滥用
手动改时间是给"确实需要补录"用的。日常留痕就让它自动，时间戳的连续性本身就是可信度。
:::

## 第三步：验收与整改

验收时的用法不太一样：

| 场景 | 做法 |
| --- | --- |
| 发现问题 | 用确认页的**箭头**指出位置，**矩形**圈出范围，**文字**写问题 |
| 整改前后对比 | 同一位置拍两次，第一次标问题，第二次标"已整改" |
| 隐蔽工程 | 隐蔽前拍，水印备注写"隐蔽前" |

标注是**烧录**进照片的，所以发给监理、甲方、施工班组，谁打开都看得到。

## 第四步：归档

照片按文件名天然可归档：

```
engCamera_XX项目主体结构_20261104_093012.jpg
engCamera_XX项目主体结构_20261104_140533.jpg
```

按文件名前缀筛选 → 拖进项目文件夹 → 完事。

如果同时管多个项目，按工程名筛选即可区分。

## 第五步：交付

交付时给甲方的资料包，照片自带：

- ✅ 拍摄时间（不可事后伪造，连续性好判断）
- ✅ 拍摄地点（地址 + 经纬度可选）
- ✅ 现场天气（可以印证"雨天停工"这类说法）
- ✅ 施工部位与工序（备注）

::: tip 加一层保险
需要更强的可信度时，在编辑器里打开「显示经纬度」——地址后面带上精确坐标，对方可以在地图上核对。
:::

## 常见错误

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 所有工序用同一个备注 | 三周后分不清 | 每次拍前改备注 |
| 不开「拍照后确认」 | 拍糊了才发现，只能删 | 现场验收场景保持开启 |
| 用手动时间"美化"照片 | 时间不连续，反而可疑 | 只对确实需要补录的用 |
| 不建工程组，一个水印走天下 | 多项目照片混在一起 | 一个项目一个工程 |
| 不导出备份 | 换机后配置全丢 | 交付前导出一次模板 |

## 一句话总结

**让照片自己说话。** 拍的时候多花 5 秒填备注，事后省 30 分钟翻记录。
