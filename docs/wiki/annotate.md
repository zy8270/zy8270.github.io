# 拍照确认与标注

开启「拍照后确认」（默认开）后，快门不会直接落盘，而是先进确认页——这里可以标注、改水印、再决定保存还是丢弃。

## 确认页布局

| 元素 | 说明 |
| --- | --- |
| **白框照片区** | 固定 3:4 确认框，照片按真实比例居中；横拍/倒置照片在框内也保持正确方向 |
| **水印** | 显示为烧录后的样子（已冻结本次的时间/位置/天气） |
| **左下笔按钮** | 进入水印编辑器（改本次的水印内容） |
| **右下撤销按钮** | 逐笔撤销标注 |
| **工具条** | 箭头 / 矩形 / 画笔 / 文字（`A`） |
| **颜色点** | 六色预设（红/橙/蓝/绿/紫/黑）+ 彩虹自由选色 |
| **中间蓝色按钮** | 保存（带标注一起烧录） |
| **右下 X** | 丢弃本次照片 |
| **顶栏提示** | 操作提示，如"点击图片任意位置添加文字" |

::: warning 相机已关闭
确认页期间相机是**解绑状态**（省电、避免常亮闪光灯一直亮）。返回相机页会自动重新绑定。
:::

## 四种标注工具

### 箭头

拖动绘制一个带箭头的直线，适合指出"这里有问题"。

### 矩形

拖动绘制一个空心矩形框，适合圈出问题区域。

### 画笔

自由手绘线条。

### 文字（A）

1. 选中 `A` 工具
2. 点图片任意位置，弹出「添加文字」对话框
3. 输入文字，点「确定」
4. 文字出现在点击位置，带白色细框与两个手柄：
   - **右上 X**：删除该文字
   - **右下 ↕**：旋转 / 缩放
5. 拖动文字本体可移动位置

## 颜色

- 六色预设：红 / 橙 / 蓝 / 绿 / 紫 / 黑（默认红）
- 彩虹图标：打开自由选色器，任意颜色
- **改颜色立即生效**：点击或拖动任意标注即选中它，再点色点就改这个标注的颜色
- 新加的标注自动选中

## 逐笔撤销

点右下角撤销按钮，每次撤销**最后一笔**（标注或文字）。

## 双指缩放

确认页支持双指缩放：

- 放大后**松手保持缩放**，单指继续落笔
- **笔画粗细定格在落笔时的倍率**：放大时画的笔画永久更细，与成片一致
- 文字操作手柄尺寸恒定，不随缩放变大
- 双指放大可填满整个确认框

::: tip 精细标注
要圈出一个很小的螺栓或裂缝？先双指放大到 3~4 倍，再落笔，笔画会细到合适。
:::

## 长按拖动水印

**长按水印块**可以拖动改位置：

- 长按触发时会有一次震动提示"可以拖了"
- 拖动的位移只影响**本次保存**，不改全局水印位置
- 水印方向锁定与照片同向（不跟随当前手机朝向）

::: tip 为什么是长按
单击水印区是"进入编辑器"，长按是"临时挪一下"，两种意图分开，避免误触。
:::

## 编辑本次水印内容

点左下角**笔图标**进入编辑器：

- 可以改本次照片的字段内容（比如补一句备注）
- 改完点「保存」回到确认页，水印会更新
- 冻结的锚点与动态值保持不变（时间/位置仍是快门那一刻的值）
- 内容样式模板跟随当前工程

## 保存与丢弃

| 操作 | 结果 |
| --- | --- |
| 中间蓝色按钮 | 保存到相册（标注一起烧录） |
| 右下 X | 丢弃，文件删除 |

::: tip 保存后的相册顺序
水印版在前；若开启了「同时保存原片」，原片（带 `(1)`）排在第二张。
:::

## 关闭确认模式

设置 → 拍照后确认 → 关。快门直接落盘，速度快但没法标注。

## 常见问题

**确认页相机黑屏？**
这是正常设计——确认页期间相机关闭。点返回后相机会重新绑定。

**标注画不出来？**
确认选中的工具（工具条高亮的是当前工具），且手指落在照片区域内（白框外不响应）。

**文字框太小白框看不清？**
白框只是 UI 提示，**不会烧录**。成片里只有文字本身。

**横拍照片在确认框里上下留白？**
固定 3:4 确认框 + 照片真实比例，横拍照片两侧会留空。这是为了保持水印位置的几何关系，双指放大可填满。

**撤销能撤销全部吗？**
逐笔撤销，多点几次即可清空。
