# 防伪码与品牌角标

成片右下角可以放两样东西：**防伪码**（一行内容指纹）和**品牌角标**（一块品牌标识）。两者共用同一块区域、同一个重力旋转矩阵——横拍、倒置都稳定贴在**物理右下角**。

两个是**独立开关**：

| 项 | 默认 |
| --- | --- |
| 防伪码 | **关** |
| 品牌角标 | **开** |

入口都在水印编辑器字段列表里的「**防伪码&品牌**」一行。

## 防伪码

### 它是什么

成片右下角一行 **14 位大写字母 + 数字**，由**照片画面内容**算出（加盐 `EngCameraRnzhy`），不是随机数。换句话说：同一张画面算出的码必然相同，画面变了码就变。

### 怎么校验

项目根目录有配套脚本 `verify_anticounterfeit.py`：

```bash
python verify_anticounterfeit.py 照片.jpg --code F9WFV37M4JVKC2
```

脚本会重算画面指纹并与照片上显示的码比对，给出**偏差百分比**：

| 偏差 | 判定 |
| --- | --- |
| ≤ 5% | 未修改 |
| 5~12% | 轻微处理 |
| > 12% | 疑似篡改 |

实测抗性：JPEG q20 重压缩 0%、缩到 30% 再放大 0%、模糊 r=3 为 0.2%、锐化 0.5%、亮度 -20 为 2.3%、对比度 ×1.3 为 4.6%。

### 两个重要边界

::: warning 这是内容指纹，不是密码学签名
盐只起混淆映射的作用，知道算法的人可以重算伪造。它的用途是"发现照片被改过"，不是"证明照片出自某人"。
:::

- **忽略水印、无视批注**：指纹算在**未加水印、未批注**的原始画面上。所以带批注的那张不参与校验（水印版本身也是先算码再烧水印，所以无批注那张可校验）
- **小面积局部改动检测不出来**：约 2% 画面的改动低于 14 位能装的极限；画面下方约 37.5% 不在采样区，该段改动需要用脚本的 `--original 原始成片.jpg` 模式对比

### 手动改码

编辑器里可以手动填码（14 位大写字母 + 数字），或点标题右侧的「自动生成」。

::: tip 手动码不参与校验
手动填的码只影响图上显示的文字，不参与内容校验。想要可校验，就用自动生成的。
:::

## 品牌角标

### 内置默认标识

右下角两行**等宽右对齐**：

```
工程水印
相机 [真实可验]
```

第一行大字，第二行缩小并配一个半透明圆角块。这是应用自带的标识，与你的工程名无关。

### 换成自己的

| 操作 | 说明 |
| --- | --- |
| **选择图片** | 从相册导入自己的图片，整块替换（按画面宽 16% 等比缩放，自动给防伪行让位） |
| **编辑文字** | 展开抽屉，逐行输入三行文案；留空回默认 |
| **重置** | 同时清掉图片与文字，回到内置默认 |

::: warning 导入图片后文字不生效
整块由图片替代，三行文字输入框就不起作用了。这是设计如此，不是 bug。
:::

自定义文字时两行仍**强制等宽**（保持视觉整齐），字号会自动反解并带绝对上下限——写一两个字不会撑成巨无霸。

### 为什么是自有角标

这个功能源自用户诉求"加他人品牌标识"。直接复刻有侵权风险，所以做成了**自有角标 + 可导入替换**：你需要什么标识，自己导入即可。

### 出现范围

角标只出现在**照片与拼图**里，**视频不出**——与防伪码的现状一致。

## 常见问题

**升级后右下角多了一块东西？**
品牌角标默认开。不想要就去「防伪码&品牌」把它关掉。

**防伪码和角标能同时显示吗？**
能，共用一块区域但互不覆盖：角标在上，防伪行在下。

**横着拍，码会不会歪？**
不会。两者共用同一套重力旋转矩阵，横拍、倒置都贴在物理右下角。

**预览里看到的码和成片一样吗？**
预览显示的是占位符 `EngCameraRnzhy`。真实码要等成片才算得出（要基于画面内容），所以预览只是位置与样式的预览。

**水印放太高会影响校验吗？**
会。编辑器里会提示「水印位置过高，防伪校验会失真」——水印压到采样区会干扰指纹计算。

**拼图里的每张照片都有码吗？**
拼图是先烧水印再拼合，每张格子里是完整的带码照片。
