# 语言与主题

## 语言

设置 → 语言 / Language：

| 选项 | 行为 |
| --- | --- |
| 跟随系统语言 | 系统是中文 → 中文；否则 → English |
| 中文 | 强制中文 |
| English | 强制英文 |

切换**立即生效**，不需要重启。

### 哪些会翻译

| 内容 | 翻译 |
| --- | --- |
| 界面文案（按钮、提示、对话框） | ✅ |
| 模板名称（经典工程蓝 → Classic Blue） | ✅ |
| 内置字段标签（位置 → Location） | ✅ |
| 系统提示（定位失败、保存失败等） | ✅ |
| 你自己填的字段标签与内容 | ❌（用户数据，不翻译） |
| 水印里的地址、天气文本 | 地址跟随 Geocoder 语言，天气词跟随界面语言 |

::: tip 为什么用户数据不翻译
"三层梁板钢筋绑扎完成"翻译成英文毫无意义，而且会让不同语言的同事看不懂同一张照片。
:::

## 主题

设置 → 外观：

| 选项 | 行为 |
| --- | --- |
| 跟随系统 | 系统深色 → 夜间；浅色 → 日间（默认） |
| 日间 | 强制浅色 |
| 夜间 | 强制深色 |

### 主题影响什么

| 区域 | 是否跟随主题 |
| --- | --- |
| 顶栏、底栏、设置抽屉 | ✅ |
| 编辑器面板 | ✅ |
| 相机页取景区外背景 | ✅ |
| 拍照确认页白框外背景 | ✅ |
| 确认页白框内的透明格子 | ✅（日间白灰格 / 夜间深灰格） |
| **水印本身** | ❌ 水印颜色由模板与模板选项决定 |

::: tip 水印不跟随主题
水印是"画进照片"的内容，必须与主题无关——否则同一个工程在白天和晚上拍出的照片水印颜色不一样。
:::

## 常见问题

**切换语言后部分文字还是中文？**
检查是否有未翻译的新文案（应用会持续补齐）。你自己填的标签与内容本来就不翻译。

**夜间模式下看不清水印？**
水印颜色是模板设置。切到夜间主题后，如果模板用深色文字配深色照片，可到编辑器调"正文文字颜色"。

**英文界面下模板名还是中文？**
模板名随语言切换，但**缩略图里的示例文字**是渲染出来的图片内容（示例数据），不跟随语言。

**能只改水印语言不改界面吗？**
不能。语言是全局的。想只改水印标签，可在编辑器里手动把标签改成想要的文字（那就是自定义标签了）。
