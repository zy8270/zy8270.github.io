# 拍照

拍照是应用的主流程：预览 → 快门 → （可选）确认标注 → 保存。

## 拍一张的完整流程

1. **对准画面**，确认取景器里的水印内容（时间、位置、天气、备注）符合预期
2. **点快门**（中间大圆按钮）或按**音量键**（设置中默认开启）
3. 若开启「拍照后确认」（默认开），进入确认页：
   - 需要标注就直接画
   - 不需要就点中间蓝色按钮保存
   - 后悔了点右下 X 丢弃
4. 若关闭「拍照后确认」，快门后直接落盘，预览会短暂闪黑一次作为快门反馈

## 快门反馈

拍照成功瞬间，取景画面会**短暂闪黑一次**，模拟机械快门。这是视觉反馈，不是黑屏故障；连拍不受影响。

## 音量键拍照

设置项「音量键拍照」默认开。按下音量加或音量减都等同快门。

::: tip 为什么保留这个
戴手套、单手、或者手机装在支架上时，按音量键比点屏幕稳得多。
:::

## 快门声音

设置项「快门声音」默认**关**。开启后拍照会播放快门音——部分国家/地区法规要求相机必须有快门声。

## 拍照后确认

| 状态 | 行为 |
| --- | --- |
| 开（默认） | 快门 → 确认页（可标注）→ 手动保存/丢弃 |
| 关 | 快门 → 直接保存到相册 |

::: warning 关闭确认的取舍
关闭后连拍更快，但拍废了只能事后从相册删。建议至少在现场验收、留痕场景保持开启。
:::

## 成片比例与方向

- 成片比例与预览一致（3:4），不会被裁掉预览里看到的内容
- 横拍、倒置拍照时，成片方向自动对齐系统相机，水印文字保持正立
- 水印位置按**物理重力**解释，横拍选"下方"依然出现在桌面那侧

## 同时保存原片

开启「同时保存原片」后，每次拍照会额外保存一份**无水印原片**：

- 水印版为主动作，原片文件名带 `(1)` 后缀
- 相册里两个版本统一排序：水印版在前，原片第二张

## 保存位置与文件名

默认保存到 `DCIM/Camera/`，文件名规则：

```
engCamera_<工程名>_<yyyyMMdd>_<HHmmss>.jpg
```

- 工程名为空 → `engCamera_<时间>.jpg`
- 工程名中的非法字符自动清理，空白转下划线，最长 24 字

详见 [保存位置与文件名](/wiki/files)。

## 拍照失败怎么办

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 相机未就绪 | 相机还没绑定完成（刚启动或刚从编辑器返回） | 等 1~2 秒重试 |
| 无相机权限 | 权限被拒 | 到系统设置给应用开相机权限 |
| 拍照失败 | 系统级异常 | 重试；持续失败请重启应用 |
| 保存失败 | 目标目录不可写（多为 SAF 目录授权失效） | 设置里重新选择保存文件夹 |

## 连续拍摄

- 确认模式关闭时，可以按住快门连拍（每次快门独立保存）
- 确认模式开启时，每次都要走一次确认页；想快速连拍建议临时关闭
- 「计数」字段在**每次保存成功后**自动 +1（默认关闭，需在编辑器里打开）
