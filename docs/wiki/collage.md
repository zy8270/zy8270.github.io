# 连拍拼图

一次走访要拍很多张现场照，逐张发给客户既啰嗦又容易漏。**连拍拼图**把多张照片按模板拼成一张记录页，直接发出去就是一份完整留痕。

入口在相机页底栏右侧的**拼图图标**，进入后顶栏标题变为「连拍拼图」。

## 怎么用

1. 点底栏右侧的拼图图标进入模式
2. 连按快门拍照（照片先落缓存，**不落相册**）
3. 需要的话点 ⊕ 从相册多选加图（见下文）
4. 点左下角缩略图打开**连拍预览**，拖动排序、删掉不要的
5. 点「保存拼图」，合成一张整页

## 拍的照片会烧水印吗

会。每张照片**冻结拍摄那一刻的水印**——模板、样式、字段值、时间、地点、天气全部冻结。所以：

- 中途改了水印，只影响之后拍的照片，已经拍的保持原样
- 这符合"记录当时"的语义：几点拍的现场就显示几点

::: tip 只编码一次
"冻结设置"不等于"提前编码"。烧录在保存拼图时一次性完成，全程只编码一次 JPEG，不会因为先进缓存而多代损失。
:::

## 从相册加图

快门上方胶囊中间有个 **⊕ 按钮**，点开是系统照片选择器，可以**多选**相册里的图片加进拼图，和连拍的混排在一起——边拍边加边拼。

## 拼图模板

内置 **6 款**，分两套版式家族。

### 公文风（原尺寸并排）

| 模板 | 特点 |
| --- | --- |
| **无模板** | 纯白缝网格，最干净 |
| **客户拜访** | 红实底标题带（左标题 + 右日期）、粗细双线、信息行、备注、右下红字落款 |
| **工作汇报** | 红实底标题带（居中标题、字距拉开）、单细线、信息行、备注、右下红字落款 |

这套的版式是**原尺寸并排**：照片保持原生尺寸，完全不缩放、不裁剪；行内按各自原生宽并排，页宽由最宽一行反推。

::: tip 关于白边
全同方向的照片（相机输出恒 3:4）任意列数都零白边。1 列且横竖混排时会出现白边——不缩放的前提下竖图与横图宽度不同，页宽必须按宽的算，这是几何必然，不是 bug。
:::

### 3:4 等格风

| 模板 | 页眉 | 留白填充 |
| --- | --- | --- |
| **马克-工作** | 居中粗黑体标题 + 蓝色双线 | **原图模糊底** |
| **今日-客户** | 居中宋体标题 + 日期 + 红色细线 | 浅灰底 |
| **今日-工作** | 公文装饰边框（曲线转角）+ 疏排宋体标题 | 浅灰底 |

这套是**固定 3:4 竖格**：照片等比内嵌到格子里，竖图正好填满，横图按宽度内嵌、上下留白自动填充。

## 连拍预览

点左下角按钮打开预览面板（按钮背景是最后一张的缩略图，中间压着「N张」）：

| 操作 | 说明 |
| --- | --- |
| **长按拖动** | 换位（拖动格放大浮起跟手，其它格弹簧让位；单列时纯上下躲闪） |
| **右上角垃圾桶** | 删除这一张 |
| **同步当前水印** | 把当前水印一次性覆盖到所有连拍照片（相册导入的图不参与） |
| **模板设置** | 换模板、改列数、填标题与字段 |

<div class="shot-wide">
  <img src="/shots/collage-preview.webp" alt="连拍预览" />
</div>

::: tip 返回键分层
预览开着时按系统返回键 = 关预览回到拍照（不退出模式）；预览关着时按返回 = 退出拼图模式（会二次确认，因为缓存会丢）。
:::

## 保存

- 点「保存拼图」开始合成，显示**圆环进度 + 百分比 + 取消按钮**
- 照片保持原生尺寸、完全不缩放不裁剪
- 超过内存预算时整体等比缩小，并在保存后提示实际输出尺寸
- 取消后**保留连拍缓存**，可以重来

::: warning 取消的两个已知限制
JPEG 编码本身不可中断，在编码阶段取消可能留下不完整文件；单张处理中也要等当前这张处理完才响应取消。
:::

## 二次确认

以下操作都会先问一次（会丢数据或覆盖数据）：

- 退出拼图模式（缓存会丢）
- 生成拼图
- 同步当前水印（会覆盖已拍照片的水印）
- 删除单张

## 常见问题

**连拍的照片在系统相册里找不到？**
正常。连拍照片落应用缓存，不进相册；只有「保存拼图」产出的那张整页才会进相册。

**中途退出会怎样？**
会二次确认。确认退出后缓存清空，已拍的照片都不保留（还没合成）。

**拼图里的相册图片能带水印吗？**
不能。相册图片按原样贴入，水印只烧相机拍的那些。

**横图上下有大片留白？**
3:4 等格模板的设计如此——格子固定 3:4，横图按宽度内嵌自然上下留白。想让横图也填满，换公文风模板并选多列。

**能拼几张？**
受内存预算限制。实测 2 列 4 张（约 71MP）与 1 列 4 张（约 56MP）都能保持原生分辨率。张数更多时整体等比缩小。
