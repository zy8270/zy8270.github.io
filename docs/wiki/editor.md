# 水印编辑器

点相机页的水印浮层进入编辑器。这里是水印内容的"主控台"。

## 界面分区

| 区域 | 说明 |
| --- | --- |
| **顶部栏** | 返回 / 标题「水印编辑器」+ 当前工程名 / 重置 / 保存 |
| **预览区** | 上半屏，显示水印实时效果；左上角是模板入口，右上角是相机预览开关（眼睛） |
| **模板选项** | 可折叠区域，列出当前模板的可调参数 |
| **字段列表** | 每个字段一行：开关 / 拖动排序手柄 / 标签 / 当前值 / 删除 |
| **添加字段** | 列表底部的大按钮 |
| **工程组** | 右下角浮动按钮 |

## 顶部栏

| 按钮 | 作用 |
| --- | --- |
| ← 返回 | 放弃未保存的修改，回到相机页 |
| 标题 + 工程名 | 显示当前正在编辑哪个工程 |
| ⟳ 重置 | 把当前模板的字段值与样式恢复为初始状态（**不切换模板**，不动水印位置与重力设置）；会二次确认 |
| 保存 | 保存到当前工程，回相机页 |

::: warning 返回 vs 保存
返回不会自动保存。改完记得点**保存**，否则修改丢失。
:::

## 预览区

### 模板入口（左上）

点预览区左上角的**调色板图标**打开水印模板选择器（详见 [模板一览](/wiki/templates)）。

### 相机预览开关（右上眼睛）

| 状态 | 预览背景 |
| --- | --- |
| 闭眼（默认） | 取景器截帧（进入编辑器瞬间的画面） |
| 睁眼 | 相机实时画面 |

睁眼后液态玻璃的折射效果实时可见，调参更直观。设置项「取景器截帧背景」关闭后，闭眼状态改用几何图案背景。

::: tip 为什么默认闭眼
编辑水印可能要花几分钟，一直占用相机会耗电。想看清楚效果时再睁眼。
:::

## 模板选项

点「模板选项 · <模板名>」展开/收起。里面的可调项**随模板变化**，常见的有：

| 选项 | 说明 |
| --- | --- |
| 水印位置 | 九宫格点选（详见 [水印位置与重力](/wiki/position)） |
| 水印宽度 | 占画面宽度的比例，滑杆调节 |
| 标题文字颜色 / 正文文字颜色 | 色板选择，左侧圆形箭头为"重置到模板原始颜色" |
| 记录点 | 开关 + 大小 / 左边距 / 光晕 / 颜色 |
| 背景选项 | 折叠组，液态玻璃的圆角/折射/着色/色散/模糊 |
| 文字阴影 | 折叠组，大小 / 扩散 / 透明度 / 垂直偏移 |
| 标题底色 / 正文底色 | 经典工程蓝等模板专有 |

所有选项**随工程保存**，切换工程不会互相影响。

## 字段列表

每个字段一行：

```
[开关] [≡] 标签  [类型标记]        [🗑]
             当前值 / 说明文字
```

| 元素 | 作用 |
| --- | --- |
| **开关** | 启用 / 隐藏该字段（隐藏后不参与渲染，但值保留） |
| **≡ 手柄** | 长按拖动排序 |
| **标签** | 字段名，点击整行进入字段编辑对话框 |
| **类型标记** | `标题` 表示这是水印标题 |
| **🗑 删除** | 删除该字段（会二次确认） |

### 字段类型

| 类型 | 默认标签 | 说明 |
| --- | --- | --- |
| 工程名称 | 工程名称 | 通常作为标题，显示在标题条/首行 |
| 时间 | 时间 | 拍照时自动填写当前时间，可手动定格 |
| 位置 | 位置 | 自动定位，可手动填写 |
| 天气 | 天气 | 自动获取，可手动填写 |
| 备注 | 备注 | 纯文本，最常用的自定义内容 |
| 计数 | 计数 | 每次保存后自动 +1 |
| 自定义 | 用户指定 | 标签与内容都由用户填写 |

### 编辑字段

点任意字段行打开「编辑字段」对话框：

<div class="shot-wide">
  <img src="/shots/field-dialog.webp" alt="编辑字段" />
</div>

| 区域 | 说明 |
| --- | --- |
| **标签** | 字段显示名（会随界面语言翻译，见下方说明） |
| **内容** | 字段值；留空表示"拍照时自动获取" |
| **类型相关选项** | 时间/位置/天气有各自的自动值刷新与定格 |
| **显示经纬度** | 位置字段专有，在位置文本尾部附 `(纬度, 经度)` |
| **最近使用** | 点击快速填充历史值 |
| **底部按钮** | 重置 / 取消 / 确定 / **确定并保存** |

::: tip 确定 vs 确定并保存
「确定」只更新字段并留在编辑器；「确定并保存」更新后**直接保存并回到拍照页**——现场连续拍摄时用这个，少两次点击。
:::

### 标签会随语言翻译

内置字段的标签（工程名称 / 时间 / 位置 / 天气 / 备注 / 计数）是**系统文案**，会随界面语言自动切换（英文界面显示 Project name / Time / Location / Weather / Note / Count）。

你**自己写的**标签与内容不会被翻译——它们是用户数据。

## 添加字段

点「+ 添加字段」打开对话框：

| 项 | 说明 |
| --- | --- |
| 标签 | 不填默认为"备注" |
| 内容 | 可不填，之后在字段编辑里补 |

也可以先选**字段类型**（工程名称 / 时间 / 位置 / 天气 / 计数 / 备注 / 自定义），选中类型后会带上该类型的默认标签与自动行为。

## 保存与生效

- 点**保存**后，相机页的水印立即刷新
- 当前工程的所有改动（字段值、字段顺序、开关、模板样式、水印位置）都会持久化
- 重启应用、覆盖升级都保留

## 常见问题

**改了没生效？**
忘记点保存。返回不会自动保存。

**模板选项找不到某个参数？**
参数随模板变化。液态玻璃有圆角/折射/色散，经典工程蓝有标题底色/正文底色——不同模板暴露的东西不一样。

**重置会删我的内容吗？**
「重置当前模板」只把字段值恢复为默认文字、样式恢复为模板初始状态，**不删字段、不切模板**。删除字段是单独的操作。

**字段顺序能自定义吗？**
能，长按左侧 `≡` 手柄拖动。
