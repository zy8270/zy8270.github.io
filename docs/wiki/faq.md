# 常见问题

按主题归类。找不到答案可以在 [GitHub Issues](https://github.com/zy8270/engCamera/issues) 反馈。

## 安装与启动

### 装不上 / 提示"未知来源应用"

APK 从 GitHub 下载，不是应用商店分发，侧载必然有此提示。在系统设置里为本文件管理器/浏览器允许安装未知应用，然后重试。

### 覆盖安装会丢数据吗？

不会。工程组、模板、字段值、设置都存在 DataStore，覆盖安装保留。

### 启动闪退？

- **Android 9 及以下**：旧版本（v0.6.12 及之前）在无存储权限时查询媒体会崩溃，v0.6.13 已修复。请升级到最新版。
- 其他情况：请提供机型、系统版本、复现步骤到 Issues。

### 首次启动黑屏几秒？

相机绑定需要时间，属于正常。如果一直黑屏，检查相机权限是否被拒。

## 拍照

### 快门按了没反应？

- 相机未就绪：等 1~2 秒
- 录像模式下按快门是开始录像，不是拍照
- 确认权限与相机没有被其他应用占用

### 拍出来水印位置和预览不一样？

不应该。预览与烧录共用同一套排版代码。若发现差异，请提供机型、模板、持机方向。

### 连拍会中断？

开启「拍照后确认」时每张都要走确认页。想连拍请到设置里关闭。

### 照片很糊？

- 检查画质档位是否选了低分辨率
- 检查是否变焦倍数过高（电子变焦是裁切）
- 暗光下对焦可能失准，点一下主体再拍

### 音量键没反应？

设置 → 音量键拍照 → 确认开启。

## 水印与模板

### 换了模板，我填的内容没了？

字段值按**类型**对位保留，不会丢。如果新模板没有该类型的字段位，切回原模板即可看到。

### 切换模板后字段开关变了？

已有字段的启用/隐藏状态会**跟随你当前的设置**，只有新出现的字段才用模板默认值。

### 模板选择器闪退？

v0.6.13 修复了"今日·打卡1"切换/进编辑器的闪退（双 CUSTOM 字段 id 冲突）。升级到最新版。

### 液态玻璃不折射？

- 需要 Android 13 及以上
- 编辑器点眼睛打开实时预览确认
- 低版本自动退化为半透明玻璃底（排版不变）

### 圆角拉到 50% 变形了？

50% 是正半圆封顶，超过会让 SDF 退化。建议 15%~50%。

### 模板能自己做吗？

网页模板可以（导出 HTML → 改样式 → 导入）。原生模板需要改源码。

### 水印太宽/太窄？

编辑器 → 模板选项 → 水印宽度滑杆（占画面宽度比例）。

## 位置与天气

### 位置一直显示"未获取定位"

编辑器里位置字段的编辑对话框会给出三态提示：

1. **未获得定位权限** → 点"去授权"
2. **系统定位服务未开启** → 点"去开启"
3. **暂时无法获取定位** → 点"刷新定位"重试

### 地址只有"中国"

系统 Geocoder 太粗（常见于无 GMS 机型）。应用会自动降级在线反查；如果无网，会显示裸坐标。连网后点"刷新定位"。

### 地址里带着邮政编码？

系统地理编码返回的原文自带。位置字段 →「地址选项」→ 关掉「邮编」层级（默认已关）。

### 地址太长 / 想调整层级顺序？

位置字段 →「地址选项」，8 个层级可逐个开关，也能用 `↑` `↓` 调顺序，改完即时回填预览。设置跨模板保留。

### 天气不更新

天气有缓存。点字段编辑里的"刷新天气"强制更新。

### 相机页老是有定位提示条？

只对曾经授权过定位的用户显示。右侧 X 可以关闭；系统设置里打开定位后会自动恢复。

### 能给不同工程用不同地址吗？

位置是工程级数据，但自动定位结果与工程无关。要固定地址请手动填写（定格）。

## 标注与批量

### 确认页相机黑屏？

正常设计——确认页期间相机关闭（省电 + 避免闪光灯常亮）。返回后自动重绑。

### 标注画不出来？

确认工具已选中，且手指落在照片区域内（白框外不响应）。

### 文字的白框会烧录吗？

不会。白框只是 UI 提示，成片里只有文字本身。

### 双指放大后笔画太细？

这是设计——笔画粗细定格在落笔时的倍率，放大时画的笔画永久更细，与成片一致。

### 批量加水印最多几张？

30 张。更多请分多次。

### 批量处理完原图会变吗？

不会。原图不动，新文件另存。

## 保存与文件

### 照片存哪了？

默认 `DCIM/Camera/`，文件名 `engCamera_<工程名>_<时间>.jpg`。

### 系统相册看不到照片？

MediaStore 有缓存延迟，下拉刷新相册应用。

### 提示"无法写入所选目录"？

SAF 目录授权失效。到设置里重新选择保存文件夹，或恢复默认。

### 文件名中文乱码？

传输工具的问题（部分 FTP / 旧版文件助手）。文件本身没问题。

### 水印版和原片哪张在前？

水印版在前，原片（带 `(1)`）第二张。

## 连拍拼图

### 连拍的照片为什么不进相册？

连拍照片先落应用缓存，只有「保存拼图」合成的那张整页才进相册。这样避免一次走访在相册里塞一堆中间文件。

### 拼图里的相册图片没有水印？

设计如此。相册图片按原样贴入，水印只烧相机拍的那些；预览里带「相册」徽标的就是这类。

### 横图上下有留白？

3:4 等格模板（马克-工作 / 今日-客户 / 今日-工作）格子固定 3:4，横图按宽度内嵌自然上下留白。换公文风模板并选多列可以消掉。

### 中途改了水印，之前拍的呢？

不变。每张照片冻结拍摄那一刻的水印。想让全部统一，在预览里点「同步当前水印」。

### 保存到一半取消了？

连拍缓存保留，可以重来。但 JPEG 编码不可中断，在编码阶段取消可能留下不完整文件。

## 防伪码与品牌角标

### 成片右下角多了一块东西？

品牌角标，默认开。不想要就去编辑器 →「防伪码&品牌」关掉。

### 防伪码能证明照片没被 P 过吗？

能发现**大面积改动**，但不是密码学签名。判定按偏差百分比：≤5% 未修改 / 5~12% 轻微处理 / >12% 疑似篡改。小面积局部改动（约 2% 画面）检测不出来。

### 带批注的照片校验不了？

指纹算在未加水印未批注的原始画面上。水印版本身可校验（先算码再烧水印），带批注的那张不参与。

### 能换成自己的品牌图吗？

能。「防伪码&品牌」→「选择图片」导入，整块替换。导入图片后文字输入不生效。

## 录像

### 录像没有水印？

看合成提示：
- "已保留原片" / "已保存无水印视频" → 合成失败，降级保存
- 尝试降低录像画质档位再试

### 录像时间不动？

网页模板的时间定格在开录时刻。换成原生模板即可走秒。

### 录像中旋转手机，成片位置不对？

旋转同步是逐帧计算，极端快速旋转可能有 1 帧以内延迟。

### 合成很慢？

时长与分辨率决定耗时。1080p 比 4K 快得多。

## 语言与主题

### 切换语言后部分文字还是中文？

未翻译的新文案（会持续补齐）。你自己填的标签与内容本来就不翻译。

### 夜间模式看不清水印？

水印颜色是模板设置，不跟随主题。到编辑器调文字颜色。

### 水印为什么不跟随明暗主题？

水印要画进照片，必须与界面主题无关，否则同工程白天晚上拍出不同颜色的水印。

## 其他

### 能上架应用商店吗？

这是开源项目，只通过 GitHub Releases 分发。

### 能关闭更新检查吗？

目前没有开关。检查是静默的，失败也不打扰。

### 数据能导出吗？

模板可以（全量导出到剪贴板/文件）。工程组需逐工程导出。

### 有 iOS 版吗？

没有，只做 Android。

### 怎么反馈问题？

[GitHub Issues](https://github.com/zy8270/engCamera/issues)。请附机型、系统版本、应用版本（设置底部）、复现步骤。
