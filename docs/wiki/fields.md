# 字段与内容

水印的内容由一串**字段**组成。理解字段，就理解了水印的 90%。

## 字段的三个属性

每个字段有三样东西：

1. **类型** —— 决定它怎么自动获取值（时间 / 位置 / 天气 / 计数 / 静态文本）
2. **标签** —— 显示在水印上的名字，如"位置"
3. **值** —— 实际显示的内容，如"广东省广州市天河区示例路 88 号"

## 七种字段类型

| 类型 | 自动行为 | 手动可改 | 说明 |
| --- | --- | --- | --- |
| 工程名称 | 无（静态） | ✅ | 通常设为标题 |
| 时间 | 拍照时填当前时间 | ✅ | 手动填了就定格，打"自定义"标记 |
| 位置 | 自动定位 + 反地理编码 | ✅ | 支持刷新、显示经纬度 |
| 天气 | 随定位获取 + emoji | ✅ | 支持手动填写与刷新 |
| 备注 | 无（静态） | ✅ | 最常用的自由文本 |
| 计数 | 每次保存后 +1 | ✅ | 默认关闭，需手动开启 |
| 自定义 | 无（静态） | ✅ | 标签与内容都自定 |

## 自动值 vs 手动值

时间 / 位置 / 天气这三个字段有"双轨"：

- **值为空** → 拍照时使用**自动获取**的值
- **值非空** → 使用你填的**手动值**（定格），水印上会显示"自定义"标记

想恢复自动：进字段编辑对话框，点「重置」（清空值），或点「刷新定位 / 刷新天气」拿最新值后再清空。

::: tip 什么时候该定格
- 补拍昨天的照片，但需要今天的时间戳？→ 手动填时间
- 位置偏差太大？→ 手动填准确地址
- 天气预报不准？→ 手动填"多云 26℃"
:::

## 标题字段

任意字段都可以通过字段编辑对话框里的「设为标题」变成标题字段。标题字段的特点：

- 在带标题条/标题区的模板里会显示在标题位置（如经典工程蓝的蓝条、液态玻璃的大字行）
- 一个水印只有一个标题字段

## 时间字段

自动时间格式由模板决定，常见形如：

```
2026-11-04 16:20:19
```

某些打卡系列模板会把时间拆成大字时间 + 日期 + 星期分别显示（如"今日·打卡"显示 `16:30` + `2026-10-12 星期一`）。拆分显示由模板决定，不需要你填两次。

## 位置字段

自动定位的完整链路：

1. **FusedLocationProvider** 获取经纬度（带看门狗，8 秒拿不到就降级系统 LocationManager）
2. **系统 Geocoder** 反查地址
3. 系统 Geocoder 只返回国家级（如"中国"）时，降级**在线反查**（BigDataCloud，免 key）
4. 完全失败时降级显示裸坐标

地址与天气会**持久化缓存**，重启应用不清空。

### 显示经纬度

位置字段编辑对话框里有「显示经纬度（经纬度字段）」开关（默认关）。打开后位置文本尾部会附加：

```
广东省广州市天河区示例路 88 号 (23.123456, 113.456789)
```

某些模板（如"马克·工程白"）会把经纬度作为独立行显示，受同一个开关控制。

## 天气字段

- 数据源：**Open-Meteo**（免费、无需 API key）
- 显示形如 `☀️ 晴 26℃`
- 天气词自动配扁平 emoji（晴 / 多云 / 阴 / 雨 / 雪 / 雷 / 雾 等）
- 天气字段编辑里有「天气 Emoji」开关，可关掉 emoji 只留文字
- 支持手动填写与「刷新天气」

## 计数字段

- 默认**关闭**
- 开启后每次**保存成功**自动 +1
- 值必须是纯数字
- 常用于"第 N 次巡检"、"第 N 张照片"

## 自定义字段

标签与内容都由你决定，比如：

| 标签 | 内容 |
| --- | --- |
| 施工单位 | 中建八局 |
| 施工部位 | 三层梁板 |
| 天气 | 晴 |
| 拍摄人 | 张工 |
| 检查结论 | 合格 |

::: tip 命名建议
标签尽量控制在 **2~4 个汉字**——打卡/工程系列模板的标签会做两端对齐（把"备 注"排成"备    注"），超过 4 字或含拉丁字母的标签会走自然排版。
:::

## 字段排序

长按字段行左侧的 `≡` 手柄上下拖动，顺序即渲染顺序（标题字段除外，它总是显示在标题位）。

## 字段显隐

每行左侧的开关控制启用/隐藏。隐藏的字段：

- 不参与渲染
- 值**保留**，重新打开即恢复

## 模板如何决定字段布局

不同模板对同一组字段的排布方式不同：

| 模板族 | 布局 |
| --- | --- |
| 经典工程蓝 / 液态玻璃 | 标题条 + 多行"标签：值" |
| 今日·工程 / 马克·工程 | 标题条 + 标签两端对齐的字段卡 |
| 今日·打卡 / 马克·打卡 | 大字时间 + 日期星期 + 地址 + 备注（部分字段专用位置） |
| 单行横排 | 所有字段压成一行，用 `·` 分隔 |
| 便签卡 / 极简白影 | 紧凑多行 |

详见 [模板一览](/wiki/templates)。

## 常见问题

**字段显示"未获取定位"？**
定位权限被拒、系统定位关闭，或定位暂时失败。编辑器里该字段的编辑对话框会给出三态提示并提供「去授权 / 去开启 / 刷新定位」入口。

**我改了标签但英文界面还是中文？**
内置标签会翻译，你自己写的标签不会——它们是用户数据。

**备注能显示多条吗？**
今日·打卡系列模板的备注行支持多条展示（用换行分隔）。
