# 保存位置与文件名

## 默认位置

```
DCIM/Camera/
```

这是系统相机常用的目录，大多数图库会优先扫描这里。

## 文件名规则

```
engCamera_<工程名>_<yyyyMMdd>_<HHmmss>.jpg
```

示例：

| 情况 | 文件名 |
| --- | --- |
| 工程名"一号工地" | `engCamera_一号工地_20261021_102019.jpg` |
| 工程名为空 | `engCamera_20261021_102019.jpg` |
| 工程名含斜杠 | 斜杠被清理，空白转下划线 |
| 工程名超长 | 截断到 24 字 |
| 录像 | 同规则，扩展名 `.mp4` |

## 工程名的清理规则

| 输入 | 处理后 |
| --- | --- |
| `A/B 工地` | `A_B_工地` |
| `一号  工地` | `一号_工地` |
| `施工现场（一期）` | 保留中文括号 |
| 超过 24 字 | 截断前 24 字 |
| 空 | 跳过工程名段 |

非法字符包括 `/ \ : * ? " < > |` 以及控制字符。

## 同时保存原片

设置项「同时保存原片」开启后，每次拍摄保存两份：

| 文件 | 说明 |
| --- | --- |
| `engCamera_<工程名>_<时间>.jpg` | 带水印的成片（主） |
| `engCamera_<工程名>_<时间>(1).jpg` | 无水印原片 |

相册排序：水印版在前，原片第二张。

## 自定义保存目录（SAF）

设置 → 文件保存路径 → **选择文件夹**：

1. 系统弹出文件夹选择器（SAF）
2. 选一个目录，授权访问
3. 之后所有照片与录像保存到该目录

| 项 | 说明 |
| --- | --- |
| 恢复默认 | 一键回到 `DCIM/Camera` |
| 当前路径显示 | 设置里显示"当前：{路径}" |

::: warning SAF 的坑
- SAF 目录授权可能因系统清理、应用重装而**失效**，失效后会提示"无法写入所选目录"，此时重新选一次即可
- 部分系统的 SAF 不允许选择 Download 根目录
- SAF 目录里的文件不在 `DCIM/Camera`，但本应用相册仍能识别（按文件名前缀）
:::

## 文件名的作用

文件名里带工程名，好处是：

- 多工地混拍的照片，**不打开就能按文件名区分归属**
- 归档到不同项目文件夹时，按文件名批量筛选
- 转发给别人时，文件名本身就是说明

## 常见问题

**照片没出现在系统相册？**
MediaStore 有缓存延迟。下拉刷新相册应用，或重启相册应用。应用已主动插入媒体库记录。

**保存失败：{msg}？**
多为 SAF 目录不可写。到设置里重新选择保存文件夹。

**文件名中文乱码？**
某些老式文件传输工具（如 FTP、旧版微信文件助手）对中文文件名支持不好。这是传输工具的问题，文件本身没问题。

**能改文件名前缀吗？**
不能，`engCamera_` 前缀是硬编码的——相册识别、更新检查都依赖它。

**原片和水印版哪张先？**
水印版先（主），原片第二张。
