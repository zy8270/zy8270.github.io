# 对焦、变焦与镜头

## 点击对焦测光

点取景器任意位置：

- **对焦**：在该点合焦
- **测光**：以该点亮度决定曝光
- **白平衡**：以该点色温决定白平衡

对焦圈会短暂出现，4 秒后自动回到连续自动对焦/测光。

::: tip 什么时候用手动对焦
拍远处文字、近距离构件铭牌、逆光场景时，先点一下主体再按快门，比全自动更稳。
:::

## 电子变焦

| 操作 | 效果 |
| --- | --- |
| 双指捏合 | 连续变焦（按设备支持的倍数范围） |
| 上下拖动画面（部分设备） | 连续变焦 |
| 点击右上角倍数徽标 | 在 1× / 2× 之间快速切换 |

右上角徽标始终显示当前倍数，如 `1.0×`、`2.5×`。

## 多镜头与焦段

多镜头设备（有超广角/长焦的机型）：

- **1× 继续缩小**会自动切入更广的镜头（如 0.6× 超广角）
- 取景器右上方出现**焦段胶囊**：
  - **单击**：轮询切换到下一档焦段
  - **长按**：展开半透明面板，列出设备全部焦段，点选直达
  - 点面板外区域收起面板

::: tip 单镜头设备
只有一颗后摄的机型不显示焦段胶囊；只有系统直接暴露广角焦段的机型同样隐藏胶囊，用捏合变焦即可。
:::

## 焦段胶囊会随重力旋转

横拍、倒置时：

- 焦段胶囊与倍数徽标随持机方向旋转，横竖屏都保持"右上角"
- ±90° 时胶囊变成竖排，自动下移避让倍数徽标，不会相互遮挡或越出预览边界

## 前后摄切换

右下角按钮切换前摄/后摄。

- 前摄没有 4K 档位
- 切换后画质档位菜单按新镜头的真实能力重新生成
- 切换后水印排版不变（水印与镜头无关）

## 变焦对水印的影响

水印是**叠加在成片坐标系**上的，变焦只影响画面内容，不影响水印的位置、尺寸与排版。预览放大时看到的水印大小不变，这是正确行为。

## 常见问题

**焦段胶囊点了没反应？**
单镜头设备不显示胶囊；部分设备的焦段切换在 HAL 层是异步的，点完等半秒画面才切过去。

**变焦后画质变差？**
电子变焦是数码裁切，倍数越高有效像素越少。需要清晰细节时尽量用原生焦段（面板里不带小数的档位）。

**对焦老是跑？**
暗光下对比度对焦会来回找焦点。点一下主体后立刻按快门，或开启常亮闪光灯补光。
