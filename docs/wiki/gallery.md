# 相册

相机页左下角的缩略图进入本应用的相册。

## 只显示本应用拍的

相册只列出**本应用拍摄**的照片与录像，识别依据是文件名前缀 `engCamera_`。所以：

- 系统相机、微信保存的图片不会出现在这里
- 如果你把其他图片改名成 `engCamera_` 开头，也会被识别
- 使用 SAF 自定义保存目录时，同样按前缀识别

## 排序

按**拍摄时间从新到旧**排列。同一时刻的水印版与原片，水印版在前。

## 网格列数

- 默认 **4 列**
- **双指捏合**在 3~6 列之间切换
- 列数会被记住

## 单张操作

**点击缩略图**：跳转到系统相册打开该文件（应用本身不做大图查看器）。

::: tip 为什么跳系统相册
系统相册有缩放、分享、编辑、查看 EXIF 等完整能力，没必要重造。
:::

## 多选删除

1. 顶栏右侧的**多选**按钮进入多选模式
2. 点选缩略图（可多选）
3. 顶栏显示"已选 N 项"
4. 点删除图标
5. 确认后删除

::: warning 删除是永久的
删除会同时移除文件与媒体库记录，不进回收站。请确认后再操作。
:::

## 录像标记

录像缩略图右下角有**时长标记**（如 `0:03`），照片没有。

## 返回自动刷新

从相册返回相机页时，左下角"最近照片"缩略图会自动刷新为最新一张。

## 权限

- 需要"照片/视频读取"权限才能列出媒体
- 未授权时相册显示"浏览手机相册需要存储权限"并提供「授予权限」按钮
- 授予后自动刷新

## 常见问题

**相册是空的？**
- 确认给应用了照片读取权限
- 确认确实用本应用拍过照片
- 检查保存路径设置（如果改到了 SAF 目录，那里面的文件也会被识别，但需要该目录可访问）

**照片在系统相册里，这里看不到？**
文件名前缀不是 `engCamera_`。本应用只管理自己拍的文件。

**点了缩略图打不开？**
系统没有默认图库应用时会提示"未找到可以打开的系统图库应用"。

**删除失败？**
部分系统（如某些 MIUI 版本）对媒体删除有额外限制。提示"有 N 项删除失败"时，可到系统相册手动删除。
