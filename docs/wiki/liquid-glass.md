# 液态玻璃

液态玻璃是这个应用的"招牌效果"：一张 iOS 风格的玻璃卡，边缘会**折射**背后的画面，还带一点色散。

## 它是什么

底层使用开源库 [AndroidLiquidGlassView](https://github.com/QmDeve/AndroidLiquidGlassView)（MIT），通过 **AGSL 运行时着色器**实时采样相机画面，做出"玻璃厚度 + 边缘折射 + 色散"的效果。

应用在它之上做了三件事：

1. **文字层独立**：玻璃卡只负责背景效果，文字用应用自己的排版渲染，保证与成片一致
2. **成片同款着色器**：把 AGSL 移植成 CPU 版本，烧录时用同一套数学
3. **录像逐帧折射**：用自定义 Media3 `GlEffect` 在 GLSL 里逐帧采样视频

## 三个场景的真实折射

| 场景 | 采样来源 | 实现 |
| --- | --- | --- |
| **预览** | 相机实时画面 | AGSL 实时着色器 |
| **拍照成片** | 成片位图自身 | 同款着色器的 CPU 移植 |
| **录像成片** | 视频逐帧画面 | GLSL `GlassFrameEffect` |
| **批量加水印** | 图片自身 | CPU 全分辨率渲染 |
| **拍照确认页** | 照片自身 | CPU 全分辨率渲染 |

「拖到哪里扭到哪里」——玻璃卡移动时，折射的内容跟着变。

## 系统要求

- **Android 13（API 33）及以上**：完整实时折射
- **Android 12 及以下**：自动退化为半透明玻璃底（排版、颜色、文字不变，只是没有折射）

::: tip 退化不影响成片
低版本设备的成片与预览一致——都使用退化后的半透明底。不会出现"预览有折射、成片没有"的割裂。
:::

## 背景选项（折叠组）

编辑器 → 模板选项 → **背景选项**：

| 参数 | 范围 | 说明 |
| --- | --- | --- |
| **圆角** | 0~50（占短边百分比） | 15% 为默认圆角；50% = 正半圆封顶；超过半圆的 SDF 会退化变形，不建议 |
| **折射高度 (dp)** | 12~50 | 玻璃边缘折射带的厚度 |
| **折射偏移 (dp)** | 20~120 | 折射采样点的偏移距离，越大越"厚" |
| **着色透明度** | 0~1 | 玻璃底色的不透明度 |
| **着色红 / 绿 / 蓝** | 0~1 | 玻璃底色 RGB |
| **色散** | 0~1 | 边缘彩虹色散强度 |
| **模糊半径** | 0~50 | 背景模糊程度 |

## 文字阴影（折叠组）

| 参数 | 说明 |
| --- | --- |
| 阴影大小 | 文字投影的半径 |
| 阴影扩散 | 扩散程度 |
| 阴影透明度 | 0~1 |
| 阴影垂直偏移 | 向下偏移量 |

深色玻璃底上白字看不清时，加大阴影透明度与偏移即可。

## 文字与记录点

- 标题文字颜色 / 正文文字颜色：色板选择
- 记录点：开关 + 大小 / 左边距 / 光晕 / 颜色（默认关）

## 性能说明

液态玻璃是这个应用里**最重**的模板：

| 环节 | 成本 |
| --- | --- |
| 预览 | 走 GPU，四方向（竖屏/横屏/倒置）都是 60fps 路径 |
| 拍照烧录 | CPU 全分辨率渲染，约 0.5~2 秒 |
| 录像 | GLSL 逐帧，实时 |

::: tip 老设备建议
低端机长时间使用液态玻璃预览会发热。日常拍摄用经典工程蓝等原生模板更省电，需要展示时再切液态玻璃。
:::

## 常见问题

**玻璃卡是黑的/不折射？**
- 确认系统版本 ≥ Android 13
- 编辑器里点眼睛打开实时预览，看是否恢复正常
- 预览区右上角的相机预览如果一直黑屏，可能是相机被其他页面占用

**录像里的玻璃没有折射？**
录像折射需要 GPU 路径支持，极老设备可能降级。检查成片里玻璃是否为半透明底。

**圆角拉到 50% 变形了？**
50% 是正半圆封顶，超过会导致 SDF 退化。建议 15%~50% 之间调。

**玻璃卡挡住画面了？**
调「着色透明度」调低，或换「极简白影」这类不遮挡的模板。
