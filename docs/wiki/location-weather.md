# 定位与天气

位置和天气是水印里最"活"的两个字段——它们依赖系统与网络，也最容易出问题。本篇讲清楚它们的链路与自救方式。

## 位置是怎么来的

应用用三级兜底：

```
1. FusedLocationProvider（首选，快且省电）
   ├─ 8 秒拿不到首帧 → 降级
   └─ 12 秒刷新预算内仍失败 → 降级
2. 系统 LocationManager（GPS + 网络定位）
3. 完全失败 → 显示「未获取定位」
```

拿到经纬度后再做**反地理编码**（地址）：

```
1. 系统 Geocoder 整行地址
2. 结构化字段拼接：省 / 市 / 区 / 路 / 地点
3. 结果太粗（只返回"中国"这类国家级）→ 在线反查（BigDataCloud，免 key）
4. 仍失败 → 显示裸坐标
```

::: tip 为什么要在线反查
部分无 GMS 机型（如某些 vivo / iQOO）的系统 Geocoder 只返回"中国"。在线反查能补出完整中文地址。
:::

## 天气是怎么来的

- 数据源：[Open-Meteo](https://open-meteo.com/)（免费、无需 API key）
- 有坐标即请求，随位置更新
- 天气词自动配 emoji：`☀️ 晴 26℃`、`🌧️ 雨 18℃`、`⛈️ 雷阵雨 24℃`
- 可在天气字段编辑里关掉 emoji

## 缓存

地址与天气都会**持久化缓存**：

- 重启应用不清空
- 断网时显示上一次的值，而不是空白
- 有网时自动更新

## 手动刷新

编辑器 → 点「位置」或「天气」字段行 → 编辑对话框：

| 按钮 | 作用 |
| --- | --- |
| **刷新定位** | 强制重新取一次定位 |
| **刷新天气** | 强制重新取一次天气 |

对话框里还会显示"自动定位：{地址}" / "自动天气：{天气}"，方便对照。

## 手动填写（定格）

直接在「内容」输入框里填值，就进入**手动定格**状态：

- 水印上该字段会打上"自定义"标记
- 之后拍照不再自动更新该字段
- 想恢复自动：点「重置」清空内容

::: tip 定格的实际用途
- 补拍昨天的场景，需要昨天的日期
- 站在 A 地拍 B 地的照片
- 天气 API 不准，手动填实际天气
:::

## 定位拿不到时的三种情况

编辑器里位置字段的编辑对话框会给出明确的三态提示：

| 提示 | 含义 | 按钮 |
| --- | --- | --- |
| 未获得定位权限，水印位置将无法自动填写 | 权限被拒 | **去授权** |
| 系统定位服务未开启，水印位置将无法自动填写 | 系统开关关了 | **去开启** |
| 暂时无法获取定位，可点下方「刷新定位」重试 | 权限与开关都正常，但拿不到点 | 手动刷新 |

::: warning "定位中…"不是失败
刚打开时可能显示"定位中…"，这是正在获取，不是失败。给它几秒。
:::

## 相机页的定位提示条

如果定位不可用，相机页会显示一条可点击的提示条：

- **只对曾经授权过定位的用户显示**（避免第一次打开就弹提示吓人）
- 右侧有 **X 按钮**可以关闭
- 关闭后重新拿到定位会自动复位
- 每 5 秒巡检一次系统状态，从设置里打开定位开关后会自动恢复

## 显示经纬度

位置字段编辑里的「显示经纬度（经纬度字段）」开关（默认关）：

| 状态 | 显示 |
| --- | --- |
| 关 | `广东省广州市天河区示例路 88 号` |
| 开 | `广东省广州市天河区示例路 88 号 (23.123456, 113.456789)` |

部分模板（如"马克·工程白"）把经纬度作为独立行，同样受这个开关控制。

## 已知限制

| 限制 | 说明 |
| --- | --- |
| 缓存 60 秒 / 50 米 | 短时间内不会重复定位，可能显示略微滞后的位置 |
| 离线地址 | 无网时若系统 Geocoder 也失败，只显示裸坐标 |
| 仅粗略定位 | 只授权"大致位置"时地址只能到城市级 |
| ROM 限制 | 部分系统（如某些 MIUI 省电策略）会限制后台定位 |

## 常见问题

**位置显示"未获取定位"？**
按三态提示处理：去授权 / 去开启 / 刷新定位。

**地址只有"中国"？**
系统 Geocoder 太粗。应用会自动降级在线反查；如果在线也失败（无网），会显示裸坐标。

**天气一直是旧值？**
缓存机制。点「刷新天气」强制更新，或等到下一次自动更新。

**位置和实际差几百米？**
融合定位有缓存窗口（60 秒 / 50 米）。走到新地点后点「刷新定位」。

**能给不同工程用不同位置吗？**
位置是工程级数据。但位置值通常是"自动"的，切换工程不会改变自动定位结果。要固定位置请手动定格。
