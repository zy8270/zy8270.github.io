# 水印位置与重力

水印放哪儿由两件事决定：**九宫格选择**和**重力方向**。

## 九宫格

编辑器 → 模板选项 → **水印位置**：

- 一个 3×3 网格，点任意一格把水印放到对应位置
- 九个位置：左上 / 中上 / 右上 / 左中 / 正中 / 右中 / 左下 / 中下 / 右下
- 当前选中的格子高亮（蓝色方块）

## 拖拽微调

除了九宫格，还可以直接在预览区**拖动水印**做任意位置的微调。拖动后的位置会保存到当前工程。

::: tip 九宫格 vs 拖拽
九宫格是"对齐基准点"，拖拽是"自由偏移"。先点九宫格定基准，再拖到满意位置，这样最省事。
:::

## 参照系是重力，不是屏幕

这是这个应用最容易被忽略但很重要的设计：

**九宫格里的"下方"，指的是物理重力的下方，不是屏幕的下方。**

| 持机方式 | 选"下方"时水印出现在 |
| --- | --- |
| 竖屏 | 屏幕下方 |
| 顺时针横拍 | 屏幕右侧（也就是桌面的方向） |
| 逆时针横拍 | 屏幕左侧 |
| 倒置 | 屏幕上方（也就是天花板的方向的反面） |

于是：**同一套设置，不管怎么拿手机，水印都稳定出现在"物理上靠下"的位置**。

## 重力跟随开关

设置项「水印跟随重力」默认开。

| 状态 | 行为 |
| --- | --- |
| 开（默认） | 文字恒正立，位置按重力方向解释 |
| 关 | 使用固定旋转角，水印角度不随持机方向变化 |

关闭后，设置里会出现「固定旋转角」滑杆，可手动指定 0~359° 的旋转角。

::: tip 什么时候关
极少数场景（比如手机装在固定支架上做监控）不希望水印跟着转，就关掉手动设角度。
:::

## 文字方向

- 水印文字**永远正立**（相对读者），不会因为横拍就横过来
- 模板标题条、字段行的排版方向始终不变
- 只有水印**块的位置**和**整体角度**随重力

## 标注模式下的锁定

拍照确认页、批量加水印模式下，水印**锁定与图片同向**，不跟随当前手机朝向——因为此时处理的是"已经拍好的照片"，方向以照片为准。

## 预览浮层与烧录的一致性

预览浮层显示的水印会随重力实时旋转；烧录时按成片方向（由系统相机对齐）反向换算锚点，保证成片里的位置与预览一致。

::: warning 横拍的特殊情况
横拍成片是"旋转 90° 的竖图"。预览里水印看起来在画面右侧，成片里依然是画面右侧——不会漂到别处。
:::

## 阴影与位置的坑（已修复）

历史版本里，椭圆放射阴影的外沿曾参与定位钳位，导致水印被顶离屏幕底。当前版本阴影**不参与定位**：定位只按内容区算，阴影可以自由溢出边界。

## 常见问题

**横拍时水印跑到奇怪的地方？**
确认「水印跟随重力」是开的。关闭时会用固定角度。

**水印贴边太近了？**
拖拽微调往里挪一点，或换水印宽度更小的模板参数。

**九宫格选了"下方"，但水印在中间？**
可能是拖拽偏移覆盖了九宫格基准。重新点一次九宫格格子即可回到基准位置。

**倒置拍照水印跑到顶部了？**
这是正确行为——倒置时"重力下方"就是屏幕上方。如果不想这样，关掉重力跟随。
