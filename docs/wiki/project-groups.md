# 工程组（多工地）

工程组是"整套水印配置"的快照。跑多个工地时，每个工地一套水印，切换即可。

## 打开工程组

两个入口：

1. **相机页底栏左侧**的三横线按钮（常驻快捷入口）
2. **编辑器右下角**的「工程组」浮动按钮

## 面板说明

| 元素 | 说明 |
| --- | --- |
| 标题「工程组」 | 下方显示 `N 个工程 · 点名称切换` |
| **+ 新建** | 新建工程（复制当前工程的水印内容） |
| **工程列表** | 每行：勾选框 / 工程名 / `当前` 标记 / 铅笔（重命名） |
| **勾选框** | 多选，用于批量删除、批量重置 |

## 新建工程

点「+ 新建」：

1. 输入工程名（默认"工程2"、"工程3"…）
2. 点「创建」

新工程会**复制当前工程的水印内容**（模板、字段、样式、位置全部复制），创建后自动切换过去，你可以再改它的水印。

::: tip 工程名自动作标题
设置项「工程名作水印标题」默认开——新建工程时，工程名会自动填入该工程的**水印标题**字段。所以给工程起个好名字，水印标题就自动对了。
:::

## 切换工程

点列表里的**工程名**即切换。切换后：

- 相机页水印立即变成该工程的配置
- 文件名前缀变成该工程名
- 编辑器标题显示当前工程名

## 重命名

点工程行右侧的**铅笔**图标，输入新名字，点「重命名」。

::: warning 改名不会改水印
重命名只改工程名（影响文件名与工程列表显示）。水印标题字段是独立数据，需要单独改（或新建工程时自动填入）。
:::

## 批量删除

1. 勾选要删的工程（可多选）
2. 出现删除按钮，点击
3. 确认后删除

::: warning 至少保留一个
不能删除最后一个工程。当前工程被删除时，会自动切到剩下的第一个。
:::

## 批量重置

勾选多个工程 → 点「重置勾选的工程」→ 确认。重置会把选中的工程恢复为初始水印状态（字段值回默认、样式回模板初始）。

## 文件名带工程名

工程组的名字会进文件名：

```
engCamera_一号工地_20261021_102019.jpg
```

规则：

- 非法字符（`/ \ : * ? " < > |` 等）自动清理
- 空白转下划线
- 最长 24 字
- 工程名为空 → `engCamera_20261021_102019.jpg`

详见 [保存位置与文件名](/wiki/files)。

## 典型用法

| 场景 | 做法 |
| --- | --- |
| 三个在建工地 | 建三个工程，各设不同工程名与位置 |
| 同一工地不同阶段 | 建"基础阶段"、"主体阶段"、"装修阶段"三个工程 |
| 不同检查类型 | 建"日常巡检"、"安全巡查"、"质量验收"三个工程 |
| 不同项目甲方 | 一个工程对应一个甲方，备注里写甲方名 |

## 工程组的边界

- 每个工程**独立**保存：模板、字段、样式、水印位置、重力设置
- 全局设置（保存路径、语言、主题、快门声音等）**所有工程共享**
- 计数器的值按工程独立

## 常见问题

**新建工程后水印没变？**
新建是"复制当前"，所以看起来一样。切换过去后进编辑器改内容。

**切换工程后位置变了？**
位置是工程级数据。如果该工程没设过位置，会用默认值。

**工程名改了，历史照片文件名会变吗？**
不会。文件名在保存那一刻就定死了。

**能导出工程组吗？**
模板导出是逐工程的：切到目标工程 → 编辑器 → 水印模板 → 导出 → 全量导出。
