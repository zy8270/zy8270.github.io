## 画质档位是设备真实能力

点底栏右侧的画质按钮（`HD` 等标记）打开档位菜单。菜单里的每一项都显示：

- **分辨率**，如 `4624×3472`
- **像素量级**，如 `约 16MP`
- **比例**，如 `4:3`

::: tip 为什么档位会不一样
档位由当前镜头的真实能力枚举而来，不同机型、前摄/后摄、拍照/录像的档位集合都不同。应用不会伪造档位——选了就一定支持。
:::

## 比例规则

| 场景 | 比例 |
| --- | --- |
| 预览 | 3:4（固定） |
| 拍照成片 | 与预览一致，按 ViewPort 统一裁剪 |
| 录像成片 | 与预览一致，按 ViewPort 统一裁剪 |

这意味着**预览里看到的构图就是成片的构图**，不会被裁掉边缘。

::: warning 关于 16:9
部分机型提供 16:9 录像档位，此时画面上下会被裁切到 16:9。选档时留意菜单里标注的比例。
:::

## 前摄限制

前摄自动**不提供 4K**，档位上限按硬件能力给出。

## 拍照 vs 录像档位

拍照档位与录像档位是两套独立列表：

- 拍照模式下打开菜单 → 照片分辨率档位
- 录像模式下打开菜单 → 视频分辨率/帧率档位

## 高画质与性能

| 影响 | 说明 |
| --- | --- |
| 文件体积 | 4K 录像一分钟约 200~400 MB |
| 合成耗时 | 分辨率越高，录像水印合成越慢 |
| 液态玻璃 | 高分辨率下 CPU 烧录耗时增加，但预览不受影响 |
| 机身发热 | 长时间 4K 录像会明显发热 |

::: tip 工程留痕的实际建议
- **照片**：用默认档位即可，16MP 足够看清构件细节
- **录像**：1080p 足够，4K 主要增加体积与合成时间
- **验收留痕**：拍照片比录像更好归档、更好检索
:::

## 常见问题

**找不到 4K？**
前摄不支持 4K；部分机型的 4K 只在特定镜头可用。菜单只列真实支持的档位。

**画质菜单是空的？**
相机还没绑定完成。等 1~2 秒再点。

**换了画质水印排版变了？**
不应该。水印按画面宽度比例排版，分辨率变化时相对比例一致。如果发现明显差异，请反馈具体机型与档位。
