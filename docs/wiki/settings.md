| 选项 | 说明 |
| --- | --- |
| 跟随系统 | 跟随系统深色/浅色模式（默认） |

| 夜间 | 强制深色 |

## 语言 / Language

| 选项 | 说明 |
| --- | --- |
| 跟随系统语言 | 系统是中文就中文，否则英文（默认） |
| 中文 | 强制中文 |
| English | 强制英文 |

切换后**界面立即刷新**，无需重启。模板名、字段标签、提示文案全部跟随。

详见 [语言与主题](/wiki/appearance)。

## 同时保存原片

| 状态 | 行为 |
| --- | --- |
| 关（默认） | 只保存带水印的成片 |
| 开 | 额外保存一份无水印原片（文件名带 `(1)`） |

::: tip 建议
需要留一份"干净素材"（比如以后要重新加水印、要发给设计做效果图）就开。只做留痕归档可以关。
:::

## 拍照后确认

| 状态 | 行为 |
| --- | --- |
| 开（默认） | 快门后进确认页，可标注、可改水印、可丢弃 |
| 关 | 快门直接落盘，速度更快 |

详见 [拍照确认与标注](/wiki/annotate)。

## 快门声音

| 状态 | 行为 |
| --- | --- |
| 关（默认） | 静音拍照 |
| 开 | 播放快门音 |

::: warning 法规
部分国家/地区法规要求相机必须有快门声。在那些地区请开启。
:::

## 音量键拍照

| 状态 | 行为 |
| --- | --- |
| 开（默认） | 按音量加/减都等同快门 |
| 关 | 音量键恢复调音量功能 |

## 水印跟随重力

| 状态 | 行为 |
| --- | --- |
| 开（默认） | 文字恒正立，位置按物理重力方向解释 |
| 关 | 使用固定旋转角 |

关闭后会额外出现「固定旋转角」滑杆（0~359°），可手动指定水印角度。

详见 [水印位置与重力](/wiki/position)。

## 取景器截帧背景

| 状态 | 行为 |
| --- | --- |
| 开（默认） | 编辑器预览背景用进入编辑器瞬间的取景器画面 |
| 关 | 使用深/亮两套扁平山形几何图案背景 |

::: tip 什么时候关
不想让编辑器"看到"现场画面（比如在人多的场合调水印），或者取景器画面太暗看不清水印时，关掉换几何图案更清晰。
:::

## 工程名作水印标题

| 状态 | 行为 |
| --- | --- |
| 开（默认） | 新建工程时，工程名自动填入该工程的水印标题字段 |
| 关 | 新建工程时水印标题保持复制来的值 |

## 文件保存路径

| 项 | 说明 |
| --- | --- |
| 默认 | `DCIM/Camera` |
| 自定义 | 点「选择文件夹」用 SAF 选任意目录 |
| 恢复默认 | 一键回到 `DCIM/Camera` |

详见 [保存位置与文件名](/wiki/files)。

详见 [更新与版本](/wiki/update)。

## 设置是全局的

设置项对所有工程生效。工程组只隔离水印相关配置（模板、字段、样式、位置），不隔离这些开关。

## 常见问题

**设置改完要重启吗？**
不需要，全部即时生效。

**设置存在哪？**
DataStore Preferences，随应用数据。覆盖升级保留，卸载清空。

**能恢复默认设置吗？**
目前没有"一键恢复所有设置"的按钮，逐项改回即可。
