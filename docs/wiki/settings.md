## 抽屉结构

设置分两层：

- **平铺在第一层**：外观、语言、拍照后确认、快门声音、音量键拍照
- **折叠分组**：水印设置 / 缩放倍率 / 画质设置 / 存储设置

折叠分组是**手风琴**——同一时间只展开一个，展开的内容走文档流，后面的分组随之往下移。默认全部收起。

## 外观

| --- | --- |

## 语言 / Language

| 选项 | 说明 |
| --- | --- |
| 跟随系统语言 | 系统是中文就中文，否则英文（默认） |
| 中文 | 强制中文 |
| English | 强制英文 |

切换后**界面立即刷新**，无需重启。模板名、字段标签、提示文案全部跟随。

详见 [语言与主题](/wiki/appearance)。

## 拍照后确认

| 状态 | 行为 |
| --- | --- |
| 开（默认） | 快门后进确认页，可标注、可改水印、可丢弃 |
| 关 | 快门直接落盘，速度更快 |

详见 [拍照确认与标注](/wiki/annotate)。

## 快门声音

| 状态 | 行为 |
| --- | --- |
| 关（默认） | 静音拍照 |
| 开 | 播放快门音 |

::: warning 法规
部分国家/地区法规要求相机必须有快门声。在那些地区请开启。
:::

## 音量键拍照

| 状态 | 行为 |
| --- | --- |
| 开（默认） | 按音量加/减都等同快门 |
| 关 | 音量键恢复调音量功能 |

## 水印设置（折叠组）

| 选项 | 说明 |
| --- | --- |
| **水印跟随重力** | 开（默认）时文字恒正立、位置按物理重力方向解释；关闭则用固定旋转角 |
| **固定旋转角** | 仅在关闭「跟随重力」后出现，滑杆 −180°~180° |
| **取景器截帧背景** | 开（默认）时编辑器预览背景用进入编辑器瞬间的取景器画面；关闭则用深/亮两套扁平山形图案 |

详见 [水印位置与重力](/wiki/position)。

## 缩放倍率（折叠组）

| 选项 | 说明 |
| --- | --- |
| **默认倍率** | 滑杆 0.5×~8×，按 0.1× 步进；相机启动时自动缩放到该倍率 |
| **恢复上次倍率** | 开时启动沿用上次退出前的倍率；关时用上面的默认倍率 |

详见 [对焦、变焦与镜头](/wiki/focus-zoom)。

## 画质设置（折叠组）

两个子项，点进去是单选列表（当前项高亮 + 圆形勾选，选中即时生效）：

| 子项 | 说明 |
| --- | --- |
| **照片画质** | 显示实际分辨率 · 像素量级 · 比例，如 `4624×3472 · 约 16MP · 4:3` |
| **视频画质** | 显示实际分辨率 · 帧率，如 `1920×1080 · 1080p · 30fps` |

档位由当前镜头的真实能力枚举，不伪造。**所选画质跨重启沿用**。

详见 [画质与比例](/wiki/quality)。

## 存储设置（折叠组）

| 选项 | 说明 |
| --- | --- |
| **同时保存原片** | 关（默认）只存带水印成片；开则额外保留一份无水印原片 |
| **工程名作水印标题** | 开（默认）时新建工程会把工程名自动填入该工程的水印标题 |
| **文件保存路径** | 默认 `DCIM/Camera`；可选 SAF 任意目录，也可一键恢复默认 |

详见 [保存位置与文件名](/wiki/files)。

## 底部签名区

设置抽屉最底部显示：

```

```

依次是：作者 / 发布日期 / versionCode / 应用名 / 许可证。

- **点击**打开项目主页（本站）
- 有新版本时，这里会显示红点 + "发现新版本 {v}，点击查看更新"，点击直达下载页

详见 [更新与版本](/wiki/update)。

## 设置是全局的

设置项对所有工程生效。工程组只隔离水印相关配置（模板、字段、样式、位置），不隔离这些开关。

## 常见问题

**设置改完要重启吗？**
不需要，全部即时生效。

**为什么有些设置要展开才能看到？**
水印设置 / 缩放倍率 / 画质设置 / 存储设置这四组收起后抽屉更短，常用的开关一眼可见。点分组标题整行即可展开，同级只会展开一个。

**设置存在哪？**
DataStore Preferences，随应用数据。覆盖升级保留，卸载清空。

**能恢复默认设置吗？**
目前没有"一键恢复所有设置"的按钮，逐项改回即可。
