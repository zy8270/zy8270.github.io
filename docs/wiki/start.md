# 安装与首次启动

## 系统要求

| 项 | 要求 |
| --- | --- |
| 系统版本 | Android 7.0（API 24）及以上 |
| 架构 | arm64-v8a / armeabi-v7a |
| 液态玻璃实时折射 | 需 Android 13（API 33）及以上，低版本自动退化 |
| 存储 | 约 40 MB 应用本体 + 照片占用 |
| 网络 | 可选。仅用于天气、在线地址反查、检查更新；离线可正常拍照 |

## 安装

1. 从 [下载页](/download) 获取最新 APK
2. 用文件管理器点击 APK 安装；首次会提示"未知来源"，按系统引导允许安装
3. 安装完成后点击「打开」

::: warning 覆盖升级
直接覆盖安装不会丢失工程组、模板与设置。但如果**降级**（装更老版本的 APK），Android 会拒绝，必须先卸载——卸载会清空应用内数据，请先在编辑器里导出模板。
:::

## 首次启动与权限

应用启动即进入相机页，同时按需弹出权限请求。各权限用途如下：

| 权限 | 是否必需 | 用途 | 拒绝的后果 |
| --- | --- | --- | --- |
| 相机 | **必需** | 预览与拍照 | 无法拍照，页面提示"无相机权限" |
| 位置（精确/粗略） | 可选 | 自动填写位置字段、获取天气 | 位置需手动填写，天气不可用 |
| 照片/视频读取 | 可选 | 相册列表、批量加水印选图 | 相册空白，批量加水印不可用 |
| 麦克风 | 可选 | 录像录音 | 录像无声音 |
| 通知 | 可选 | 保存/合成完成提示 | 无提示，功能不受影响 |

::: tip 只给粗略定位行不行
行。只授权"大致位置"时，应用仍能取到城市级坐标，位置字段会显示城市名而不是详细地址。要精确地址请给"精确位置"。
:::

从上到下依次是：

- **顶部栏**：闪光灯开关（左）、设置齿轮（右）
- **取景器**：3:4 比例，右上角是变焦倍数徽标
- **水印浮层**：当前工程的实时排版结果，点它进入编辑器
- **底栏第一行**：工程组入口（左）｜ 编辑 / 拍照 / 录像 模式切换（中）｜ 画质（右）
- **底栏第二行**：最近照片（左）｜ 快门（中）｜ 前后摄切换（右）

默认工程叫「默认工程」，默认模板是「液态玻璃」，水印内容是"工程施工记录 / 时间 / 位置 / 天气 / 备注"。

## 建议先做的三件事

1. **改工程名称**：点水印 → 编辑器 → 工程名称行 → 改成你的项目名 → 保存
2. **确认定位**：编辑器里看"位置"行是否显示真实地址；若显示"未获取定位"，点该行 → 刷新定位
3. **按一次快门试拍**：确认成片里的水印与预览一致

## 从旧版本迁移

- **v0.6.x 之间**：直接覆盖安装，数据自动兼容
- **v0.6.13 之前**：阴影参数会自动迁移到新默认值（宽高 50% / 深浅 30% / 扩散 70%）
- **字段顺序**：旧版本的默认字段顺序会在启动时自动迁移到新顺序（自定义顺序不动）

## 卸载前请导出

如果打算卸载重装或换机，请先备份水印配置：

1. 进编辑器 → 水印模板 → 导出 → 全量导出到剪贴板（含字段值、样式、位置）
2. 把文本存到笔记或发给自己
3. 新设备上：编辑器 → 水印模板 → 导入 → 粘贴 → 导入

详见 [模板导入与导出](/wiki/template-transfer)。
