- **长按已导入的模板**可删除

## 15 款内置模板

### 原生模板（Canvas 直绘，零额外开销）

| 模板 | 风格 | 适用 |
| --- | --- | --- |
| **经典工程蓝** | 蓝标题条 + 半透明正文，记录点圆点 | 最经典、最正式的施工记录 |
| **液态玻璃** | iOS 液态玻璃卡，边缘折射 + 色散 | 想要高级感、现代感的展示 |
| **今日·工程** | 蓝色标题条 + 标签两端对齐字段卡 | 项目介绍页、日常施工记录 |
| **今日·打卡** | 大字时间 + 日期星期 + 地址 + 备注 | 打卡留痕、巡检记录 |
| **今日·打卡1** | 打卡风格变体，头部卡配色不同 | 打卡留痕（另一套配色） |
| **马克·工程** | 标题栏 + 标签两端对齐 + 施工单位独立字段 | 需要填写施工单位/监理的项目 |
| **马克·工程白** | 白底版马克·工程，经纬度可独立成行 | 浅色背景照片 |
| **马克·打卡** | 大字时间 + 地址 + 日期 + 备注 + 验证行 | 现场打卡、需要"已验证"感的场景 |
| **极简白影** | 极简白字 + 轻阴影 | 不想遮挡画面 |
| **边框卡片** | 白色卡片 + 细边框 | 信息密度高但不抢眼 |
| **单行横排** | 所有字段压成一行 | 信息少、要极简 |
| **渐变底栏** | 底部渐变条 | 想放在画面底边 |
| **便签卡** | 便签纸风格 | 巡检、随手记录 |

### 网页模板（HTML/CSS 离屏渲染）

| 模板 | 风格 | 适用 |
| --- | --- | --- |
| **胶片场记** | 电影场记板（黑白条纹 + 等宽字体） | 有拍摄记录感、电影感 |
| **杂志卡片** | 深色杂志排版 + 衬线字体 | 需要排版设计感 |

::: tip 网页模板的特点
网页模板用 WebView 离屏渲染 HTML/CSS，样式自由度高，可以**导出 HTML 后自己改**再导入。代价是渲染比原生慢（有 WebView 池 + 缓存优化），且录像里的水印时间定格在开录时刻。
:::

## 各模板的可调项

每款模板暴露自己的参数，点编辑器里的「模板选项」展开：

### 经典工程蓝

| 参数 | 说明 |
| --- | --- |
| 记录点 | 标题条左侧的黄点开关 |
| 记录点大小 | 圆点大小 |
| 记录点左边距 | 圆点距左边的距离 |
| 光晕大小 | 圆点外围光晕 |
| 记录点颜色 | 默认琥珀色 |
| 水印宽度 | 占画面宽度比例 |
| 标题底色 / 标题文字颜色 | 蓝色标题条 |
| 正文底色 / 正文文字颜色 | 半透明正文 |

### 液态玻璃

| 参数 | 说明 |
| --- | --- |
| 水印宽度 | 占画面宽度比例 |
| 标题文字颜色 / 正文文字颜色 | 文字颜色 |
| 记录点（+ 大小 / 左边距 / 光晕 / 颜色） | 同经典模板 |
| **背景选项** | 圆角（占短边百分比，0~50）/ 折射高度 / 折射偏移 / 着色透明度 / 着色 RGB / 色散 / 模糊半径 |
| **文字阴影** | 阴影大小 / 扩散 / 透明度 / 垂直偏移 |

### 打卡/工程系列（今日·、马克·）

| 参数 | 说明 |
| --- | --- |
| 背景阴影 | 宽 / 高（长短轴倍率）/ 深浅 / 扩散 / 颜色 |
| 水印宽度 | 占画面宽度比例 |
| 各色块颜色 | 标题条、备注条、标签色等 |

### 网页模板

| 参数 | 说明 |
| --- | --- |
| 网页整体缩放 | 渲染尺寸缩放 |
| 背景透明度 | 独立于其他模板的透明度键 |

## 模板与工程的关系

- 模板是**工程的一部分**：每个工程记住自己用的模板
- 切换工程 → 模板跟着切换
- 换模板不会重置字段值（字段按类型对位保留），新模板独有的字段才用模板默认值

::: tip 字段开关会跟随你
切换模板时，已有字段的**启用/隐藏状态**跟随你当前的设置，不会被模板覆盖。只有新出现的字段才用模板默认值。
:::

## 常见问题

**模板里的字段名对不上？**
模板按**字段类型**对位，不是按标签名。同类型多个字段时按出现次序对位。

**换了模板，我填的备注没了？**
字段值会保留（按类型对位）。如果模板没有该类型的字段位，内容仍存在数据里，切回原模板即可看到。

**能自己做模板吗？**
网页模板可以：导出一个网页模板的 HTML，改样式，再导入。原生模板需要改源码，见 [从源码构建](/wiki/build)。
