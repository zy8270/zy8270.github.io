# 更新与版本

## 版本号规则

```
v0.6.32        ← 版本名（versionName）
versionCode 296 ← 版本码（整数，只增不减）
```

APK 文件名带 versionCode：`engCamera-v0.6.32-296.apk`。

最新版本以 [下载页](/download) 为准——那里的版本号与链接由站点自动从 GitHub Releases 读取，不需要手工维护。

## 自动检查更新

应用启动后**每天核对一次** GitHub Release 的最新版本。

有新版本时：

1. 设置抽屉底部出现红点 + "发现新版本 {v}，点击查看更新"
2. 点击直接打开 GitHub Release 页面

## 手动检查

设置 → 底部签名区（"Rnzhy 2026.11.15 296 engCamera MIT"）：

- 无更新时：点击打开项目主页
- 有更新时：显示红点提示，点击打开下载页

## 更新方式

### 覆盖安装

下载新版 APK 直接安装覆盖：

- 工程组、模板、字段值、设置**全部保留**
- DataStore 数据不随覆盖安装丢失

### 降级

Android 不允许降级安装。降级需要：

1. 先导出模板（编辑器 → 水印模板 → 导出 → 全量导出）
2. 卸载应用（**会清空所有应用内数据**）
3. 安装旧版 APK
4. 重新导入模板

## 版本与本站

本站的[下载页](/download)直接读取 GitHub Releases 的最新版本，版本号、文件名、大小、SHA-256 与下载链接都是自动的——发版后不需要手工改文档。

页面打开时还会向 GitHub 再核对一次，所以就算站点还没重建，访客拿到的也是最新链接。以 GitHub Releases 为准。

## 常见问题

**为什么没有应用商店版本？**
这是开源项目，通过 GitHub Releases 分发。没有上架 Google Play / 国内应用商店。

**更新提示红点一直不消？**
红点表示"有比你当前版本更新的版本"。装上新版后自然消失。

**能关闭更新检查吗？**
目前没有开关。检查是静默的，失败也不打扰。

**版本号后面那个数字是什么？**
versionCode。同一版本名可能有多个内部构建（versionCode 不同），以更大的为准。

**官网的下载链接会落后于 GitHub 吗？**
不会。下载页的版本信息是自动读取的，页面打开时还会实时核对一次。
